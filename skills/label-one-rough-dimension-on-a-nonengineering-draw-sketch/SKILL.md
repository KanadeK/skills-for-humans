## 中文

你画了一个自有普通小物摆放草图，想标一条“约多少长”帮助自己回忆时使用本篇。成果是一条与外部尺量结果相符、单位写明且标有“约”的尺寸线。Draw 自动值受页面比例和单位设置影响，不可把它当承重、施工或零件加工依据。

### 准备与输入

保存 ODG 副本，先在真实物件上用普通尺量一条边并记录单位与约数，不凭图形自己推长度。核 Draw 页面单位和图形缩放口径。只选非危险、非承重的摆放草图；真实施工尺寸应转专业流程。

### 执行

1. 从 Lines and Arrows 选 Dimension Line，沿草图那条对应边画一条标注线。
2. 读取自动显示值与单位，对照外部尺量；不一致先核比例/单位，必要时把文字明确改为“约”。
3. 检查标注线和文字不遮物件轮廓，目标边界清楚。
4. 保存重开并核该线在 Dimension Lines 层；若没有外部量度依据，撤下数值。

### 完成、常见问题与恢复

一条尺寸线与尺量大致一致、单位和“约”明确，草图仍可读。

- **数字不一致：** 核页面比例和单位，不强行相信自动值。
- **线压住形状：** 移到外侧并留引线。
- **用作施工：** 立即停止，标非工程草图。

### 假设与边界

这里只做本人普通摆放记号，禁止用于工程、建筑、电气、医疗或安全尺寸判断。你负责真实尺量与适用范围。

## English

Use this Skill for a personal sketch of an ordinary small object when one approximate length helps recall placement. Finish with one dimension line matching an external ruler check, unit shown and clearly marked approximate. Draw's automatic value depends on scale and units; never use it as structural, construction or fabrication specification.

### Preparation and inputs

Save ODG copy and measure one real object edge with an ordinary ruler, recording unit and approximate value instead of inferring from drawing. Check Draw page units and scale. Use only noncritical, non-load-bearing layout sketch; construction dimensions need professional process.

### Execution

1. Choose Dimension Line from Lines and Arrows and draw along the corresponding sketch edge.
2. Compare displayed value/unit with ruler. If mismatched inspect scale/units and explicitly mark approximate as needed.
3. Check line/text do not obscure object outline and endpoints are clear.
4. Save/reopen and verify line in Dimension Lines layer; remove numeric claim without external measure.

### Success, common problems, and recovery

One dimension agrees approximately with ruler, unit and 'about' are clear, sketch remains readable.

- **Number differs:** Check drawing scale and units, not automatic value alone.
- **Line covers object:** Move outside with guides.
- **Used for building:** Stop and mark nonengineering.

### Assumptions and limits

This is a personal layout note, never engineering, construction, electrical, medical or safety measurement. You own ruler check and use boundary.
