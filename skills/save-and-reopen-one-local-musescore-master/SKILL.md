## 中文

你已经在 MuseScore Studio 中写了自己的短谱，下一步要确认真正的原稿文件存在本机，而不是只看到打开的窗口或云端副本。完成后你能从磁盘重开 .mscz，音符、文字和谱表仍可选中修改。PDF 和图片适合审阅，却不能代替可编辑主文件。

### 准备与输入

先确认当前谱面属于自己创作或有明确许可，选本机可写的项目目录。给文件名含作品和版本而不含个人敏感信息；若目录已有同名稿，决定是更新它还是另存版本，不在不清楚时覆盖。

### 执行

1. 在 File 保存流程中明确选择保存到电脑而非云端，目标格式保持 MuseScore 原生 .mscz。
2. 保存后到文件管理器核目标文件存在及修改时间；记下实际路径，别只凭最近文件列表猜。
3. 从本机文件重新打开，检查开头与结尾小节、标题及一个可选中的音符。
4. 做一次可撤销的选中或视图操作，确认仍是可编辑谱；恢复并保存需要的状态。

### 完成、常见问题与恢复

本机 .mscz 文件能独立重开，内容与保存前一致，音符和标记仍可编辑。

- **打开的是 PDF：** 回原会话保存 .mscz，别从展平输出继续编谱。
- **提示保存到云端：** 选电脑或本地路径，核文件管理器里实际存在。
- **文件版本错：** 对照路径、时间与首尾内容，必要时另存清楚的版本。

### 假设与边界

这里只核一份本机原稿，不自动备份、不发布到 MuseScore.com，也不解决不同版本间的兼容。长期保存另做独立备份。

## English

Use this after entering an original short score to establish a real local master, not merely an open window or cloud copy. The result is a .mscz that reopens from disk with notes, text and staves still selectable for editing. A PDF or image is useful for review but is not the editable source.

### Preparation and inputs

Confirm that the score is yours or permitted and choose a writable local project folder. Name the file by work and version without personal secrets. If a file with that name exists, decide whether to update or Save As a new version rather than overwriting blindly.

### Execution

1. Choose Save to computer in the File flow, not cloud, and keep the native .mscz format.
2. Confirm file existence and current modification time in the file manager; record the actual path rather than guessing from recent files.
3. Reopen the local file and inspect first and last measures, title and at least one selectable note.
4. Make a reversible selection or view operation to confirm editability, restore intended state and save as needed.

### Success, common problems, and recovery

The local .mscz reopens independently with expected content and editable notes and markings.

- **PDF opened:** Return to the editing session and save .mscz rather than editing the review output.
- **Cloud prompt:** Choose computer/local destination and confirm the disk file.
- **Wrong version:** Compare path, timestamp and opening/ending content, then save a clearly named version.

### Assumptions and limits

This checks one local master. It does not create a managed backup, publish to MuseScore.com or guarantee cross-version compatibility. Long-term preservation needs a separate backup.
