## 中文

你有一张内容页的标题、文字和图片互相挤压，想试一个更合适的预设布局时使用本篇。成果是只改目标页布局，原文字与对象逐项仍可找到、没有落在画布外；其它页不受影响。这里调整容器结构，不以缩小全部字体掩盖内容过多。

### 准备与输入

保存 ODP 副本，列出目标页的标题、正文要点、图像或表格对象及原顺序，记下相邻两页的样貌。先观察可用布局的占位框数量，选一个承载现有信息的结构；若内容本来过多，布局可能不能替代内容取舍。

### 执行

1. 只选择目标页，使用 Slide > Layout 或侧栏布局选项选择一个预设结构。
2. 逐项核原标题、正文、图片等仍在正确层级，找出被移到画布边缘或重叠的对象。
3. 在放映预览中看字体、留白、图文是否可读，并核相邻页没有被一起换布局。
4. 若任一对象丢失或变难读，撤销再试更合适布局或缩减内容；保存重开核结果。

### 完成、常见问题与恢复

目标页的对象清单完整、布局更清楚，邻页未改，实际放映预览不截字。

- **图片不见：** 检查是否在画布外或被遮挡，必要时撤销。
- **标题太小：** 选更合适占位结构或收短标题。
- **邻页也变：** 核是否误改母版而非单页布局。

### 假设与边界

只处理一张页的预设布局，不做整套母版改造。你判断信息取舍和实际投影可读性；未进行现场观众测试。

## English

Use this Skill when one content slide crowds its title, text and image and a different built-in layout may fit. Finish with only that slide's structure changed, each original text/object accounted for and nothing stranded off canvas. Other slides remain unchanged. Adjust the container structure instead of hiding overfull content with tiny type.

### Preparation and inputs

Save an ODP copy. List target title, body points, image/table objects and their order; note adjacent slides. Inspect available layouts for appropriate placeholders. If the slide simply contains too much material, a layout alone may not solve content selection.

### Execution

1. Select only target slide and choose a built-in structure using Slide > Layout or Sidebar Layout.
2. Account for original title, body and images, checking for off-canvas or overlapping objects.
3. Preview readability of type, space and visuals; check neighbouring slides did not change.
4. Undo for lost or unreadable content, then try a better layout or reduce content; save and reopen.

### Success, common problems, and recovery

Target slide retains its object inventory in clearer layout, neighbours stay unchanged, and show preview clips no text.

- **Image missing:** Check off-canvas or behind another object, then undo if needed.
- **Title too small:** Choose a better layout structure or shorten title.
- **Other slides changed:** Check for master edit instead of slide layout.

### Assumptions and limits

This changes one slide layout, not the whole master. You judge content selection and projected readability; no live audience test is claimed.
