## 中文

你准备对自有录音做裁剪或效果处理，想先留下能继续编辑的 Audacity 4 项目时使用本篇。成果是一个独立命名、可重开的本机 `.aup4`，原 WAV/MP3 等源文件仍在原处。项目包含片段、轨道和编辑状态，不是给普通播放器直接听的成品。

### 准备与输入

确认原文件位置与修改许可，为工作项目选不同名字和目录，不启用云端上传。若已有旧项目，先决定是否新建版本，避免同名覆盖。保存之前核导入轨道确实属于目标录音而非打开了其它窗口。

### 执行

1. 使用 File > Save Project/Save 选 On your computer，给 `.aup4` 项目命名。
2. 核保存路径不等于源音频文件路径，也不覆盖旧项目。
3. 关闭项目再从本机重开，确认轨道、片段和时长仍在。
4. 再单独确认原音频文件可打开；以后要给播放器听时另用 Export。

### 完成、常见问题与恢复

原件与本机 `.aup4` 都能分别打开，项目可继续编辑，未上传。

- **只有导出音频：** 回 Audacity 用 Save 建项目。
- **项目找不到：** 核本机目录与扩展名。
- **误进云选项：** 返回本机保存，不授权上传。

### 假设与边界

项目主本不是独立备份；你负责本机位置与版本。此篇不发布、不共享录音。

## English

Use this Skill before edits to an owned recording when you need a project that remains adjustable later. Finish with a separately named local `.aup4` that reopens while original WAV/MP3 remains at its path. A project holds clips, tracks and edit state; it is not the ordinary player-ready audio export.

### Preparation and inputs

Confirm original path and edit permission. Choose a different name/folder for work project without cloud upload. If an older project exists, decide on a new version rather than overwriting. Verify the imported track is the intended recording in the active window.

### Execution

1. Use File > Save Project/Save and choose On your computer, naming the `.aup4`.
2. Check project destination differs from source audio and does not overwrite older project.
3. Close and reopen local project to confirm tracks, clips and duration persist.
4. Confirm original audio still opens separately; use Export later for player-ready file.

### Success, common problems, and recovery

Original and local `.aup4` both open independently, project remains editable and nothing was uploaded.

- **Only audio export exists:** Use Save for project.
- **Project missing:** Check local folder and extension.
- **Cloud option chosen:** Return to local save without upload.

### Assumptions and limits

A project master is not an independent backup. You own local location and versions; this does not share audio.
