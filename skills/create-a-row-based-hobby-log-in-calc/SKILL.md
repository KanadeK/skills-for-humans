## 中文

你要从空白 Calc 工作表开始记录普通爱好活动时，加载这份 Skill。成果是一张只有一个标题行、每次活动一行的私人表格，至少有两条真实获准或虚构的样本。这里先定记录结构，不做公式、排序或分享；财务、健康和他人个人信息不要放进示例。

### 准备与输入

选择本机可保存的位置，先决定每条记录都能回答的五项：事件编号、日期、类别、分钟数、简短备注。打开新工作表，确认没有覆盖别人的现有文件。编号只用作追踪，不把它当数量；暂时不知的字段可留空但须可见。

### 执行

1. 在第一行逐列输入五个短标题；每个标题只管一类信息，不把日期和类别挤在同一格。
2. 在第二行填第一条事件，在第三行填第二条；每行保留同一字段顺序，不用空行隔开记录。
3. 逐格核对两条记录：编号是否不同、日期有无歧义、分钟数是否为数字、备注是否属于该行。
4. 用清楚文件名保存为 Calc 原生 ODS，关闭前确认保存状态；下次追加从下一行开始。

### 完成、常见问题与恢复

第一行有五个唯一标题，下面两行各代表一次完整活动，文件已保存在你选择的位置。若样本是虚构的，标明它只是练习数据，不把它当真实活动统计。

- **两次活动挤在一行：** 拆成两行并逐列核对。
- **某列含两种信息：** 拆开字段再核旧行对齐。
- **保存位置不确定：** 另存为明确位置，重开核查。

### 假设与边界

假设你自己控制文件且资料无敏感性。不同 Calc 版本菜单可能变动，以当前帮助为准。整齐布局只能提高一致性，不能证明录入内容真实。

## English

Use this Skill when you start an ordinary hobby activity log in a blank Calc sheet. Finish with one header row and one event per later row, including at least two permitted or synthetic sample records. This defines the record structure; it does not calculate, sort or share. Keep finance, health and other people's personal information out of the sample.

### Preparation and inputs

Choose a location you can save to and settle five fields for each event: event code, date, category, minutes and short note. Open a new sheet and ensure it will not overwrite someone else's file. A code is an identifier, not a quantity. An unknown field may remain blank but must stay visible.

### Execution

1. Enter five short headers across row one; give each column one meaning instead of packing date and category into one cell.
2. Enter one event in row two and another in row three. Keep the same field order and do not insert blank separator rows.
3. Check both records cell by cell: distinct codes, unambiguous dates, numeric minutes and notes belonging to the correct row.
4. Save with a clear name in Calc's native ODS format and confirm saved state. The next event starts on the following row.

### Success, common problems, and recovery

Row one has five distinct headers, rows two and three each represent one event, and the file is saved where you chose. Mark synthetic samples as practice data rather than real activity statistics.

- **Two events in one row:** Split them and recheck every column.
- **A column mixes meanings:** Separate fields and recheck rows.
- **Save location uncertain:** Save As to a known place and reopen.

### Assumptions and limits

You control a non-sensitive file. Menu labels may vary with Calc version; use current Help. A tidy structure improves consistency but cannot prove entries are true.
