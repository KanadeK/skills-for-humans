## 中文

你在文稿里发现一处事实、措辞或图表引用要请自己稍后核对，暂时不应擅改正文时使用本篇。成果是一个指向准确文字范围、说明具体待查问题的 Writer 批注，原句仍完整。它是文档内的审阅标记，不等于已经给别人发消息，也不代表问题已解决。

### 准备与输入

保存 ODT 副本，选一个尽可能短却足以定位问题的文字片段。把待核问题写成可回答的一句话，例如“此处数量来自哪份原记录？”避免只写“有问题”。如果涉及隐私，不要把姓名或敏感原文复制到批注里。

### 执行

1. 精确选择目标文字，用 Insert > Comment 或当前版本同名命令。
2. 输入具体问题和需要的证据，不直接改正文，也不写没有依据的结论。
3. 退出批注后核锚点与目标句对应，Navigator 或边栏能找回该批注。
4. 保存重开，检查正文原样、批注仍在；误锚时撤销并重选。

### 完成、常见问题与恢复

有一条可回答的批注附在准确片段，原文不变，重开仍可定位。

- **批注挂错句：** 撤销，缩小选择重新插。
- **只写待办：** 补具体问题和证据需求。
- **正文被改：** 撤销正文改动，确认只留批注。

### 假设与边界

这只是本地文档内的批注，不发送通知或完成审查。你负责后续查证和处理；共享协作状态不在本篇。

## English

Use this Skill when a fact, phrase or figure reference needs later checking but body prose should stay for now. Finish with one Writer comment anchored to the precise words and stating a concrete review question, while the sentence remains intact. This is an in-document review marker, not a message to another person or proof of resolution.

### Preparation and inputs

Save an ODT copy and select the shortest passage that still identifies the issue. Frame one answerable question such as 'Which source supports this count?' rather than 'problem here'. Do not copy private names or sensitive source text into the comment.

### Execution

1. Select target words precisely and use Insert > Comment or equivalent.
2. Write a concrete question and needed evidence without changing prose or asserting an unsupported conclusion.
3. Exit comment and confirm anchor matches target sentence and is findable in Navigator or sidebar.
4. Save and reopen, checking prose unchanged and comment present. Undo a wrong anchor and reselect.

### Success, common problems, and recovery

One answerable comment attaches to the right passage, original prose is unchanged, and it remains locatable after reopen.

- **Comment on wrong text:** Undo, narrow selection and reinsert.
- **Comment is vague:** State a specific question and evidence need.
- **Prose changed:** Undo body edit and retain only comment.

### Assumptions and limits

This is a local in-document comment; it sends no notification and completes no review. You own later fact-checking and resolution; shared collaboration is outside scope.
