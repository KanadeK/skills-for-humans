## 中文

你正在做一项普通、非紧急任务，已知会被来客、换场地、休息或另一项责任中断，想让**稍后的自己**能在正确材料上继续时，用这份 Skill。产物是一个真正可找回的恢复点：当前版本、最后完成并核实的部分、下一具体动作和未决条件。它不把任务交给别人，也不替你执行 H266 的中断后重入。

### 准备与输入

先看你正在用的是哪份文件、纸张、物件或工作台，以及是否有尚未保存的变更。决定恢复点放在哪里，最好与任务材料相邻但不会被意外覆盖；便签、纸条、待办备注都可以。涉及共享空间或私人资料时，只写自己有权留下的最少线索，不把凭据、完整身份资料或他人隐私贴在公共位置。若当前操作不能安全放下，先按它本身的规则处理到可暂停状态，再写笔记。

### 执行

1. **先保住实际材料。** 保存正在编辑的版本，并确认它确实在可找回的位置；纸面材料放回标明任务的夹内。若有多个相似版本，标出唯一当前稿和仅供参考的旧稿，不用“最新那个”作定位。不要为了记笔记把未保存的东西关掉。
2. **写最后核实的点。** 用一句话说“已经做完并确认的是……”和“还没做/尚未核实的是……”。例如“第 1–2 段已对照原资料；第 3 段仍是草稿，引用未核对”。打算稍后做的事情不放进已完成栏。
3. **写第一项能直接动手的动作。** “打开〔文件/页面/盒子〕，先核对第 3 段引用的出处”比“继续写报告”有用。若下一步依赖别人回复或特定时段，写清等待谁、什么内容、何时再查，并给一个当前无需等待的可做动作或诚实标“暂无可做动作”。
4. **写一条返回触发。** 若此事有真实截止或别人依赖，放一个你会看的提醒或约定返回点；提醒只代表将来要看恢复点，不等于任务会自动完成。若没有截止，也可把纸条放在材料上，别靠脑中保留一个长串未结项。
5. **从陌生人的角度读一次。** 只看恢复点，能否找到当前材料、知道最后核实处和第一动作？若不能，补文件名/物件位置、版本、下一步，不扩成一篇日记。然后收好物件、释放共用空间；需要继续使用的设备按其实际说明安全暂停。

急停短版：“〔任务〕：当前材料在〔位置/版本〕；已核实到〔点〕；下一步〔动作〕；待〔谁/什么〕。” 时间不够时至少留下这四格，回来再补。

### 成功条件

恢复点和材料实际存在且可找回；记录能区分已核实、未完成与外部等待，指向一项可执行的下一动作，并保留必要返回点。中断后需先验证现实是否变化，不能把旧恢复点当永远有效的事实。留下笔记不等于任务完成、交接成功或保证你回来立即进入状态。

### 常见报错与补救

- **只写“明天继续”：** 补当前材料的确切位置、最后核实处和第一动作。
- **文件有改动但没保存就关掉：** 先保存并核对能重新打开；若已丢失，另走未保存文字恢复流程，不能假装恢复点含有丢失内容。
- **三份文件都叫 final：** 指定当前唯一文件与旧版用途，必要时在可控范围内改可识别名称。
- **还在等别人，却写“下一步完成第 3 项”：** 标实际依赖和下一次查点，不把等待写成已可执行。
- **便签放在公共桌上暴露私密资料：** 改成获准的安全位置和不含敏感内容的最少线索。

### 假设、替代与现实副作用

适用于普通可暂停任务，不处理危险设备操作、医疗、法律或财务决策。纸笔、可访问的语音备注或数字文字都可用，但必须自己能再次找到并辨认版本；需要辅助工具时不强迫用小字号纸条。若中断突然发生，四格短版比追求完整记录有用。未来的环境、材料和截止可能变化，因此恢复点是进入任务的地图，不是对现实的永久担保。

## English

Use this Skill while working on one ordinary non-urgent task when a visitor, location change, break, or another duty will interrupt you. Leave **your later self** a recoverable point in the right material: current version, last completed and verified work, next concrete action, and open dependency. This does not transfer the task to someone else or perform H266's re-entry after the interruption.

### Preparation and inputs

Identify the file, paper, object, or workspace currently in use and any unsaved change. Pick a note location you will find beside the material without overwriting it. A sticky note, paper slip, or task comment can work. In shared spaces or around private records, write only permitted minimal cues; do not put passwords, full identity details, or another person's private data on a public note. If an operation cannot be safely left, reach its own safe pause state first under the applicable instructions.

### Execution

1. **Preserve the real material first.** Save the current version and check it exists where you can return. Put paper work in a task-labeled folder. For similar versions, mark one current draft and any reference-only older copy. “The latest one” is not a location. Do not close unsaved work merely to write a note.
2. **State the last verified point.** Write one sentence for “done and checked” and one for “not done or not checked.” For example: “Paragraphs 1–2 compared with source; paragraph 3 remains a draft and its citation is unchecked.” Planned work does not belong under completed.
3. **Name the first directly doable action.** “Open [file/page/box] and check paragraph 3's citation source” beats “continue report.” If it depends on another person's reply or a time window, name who and what you await and when to check. Give one independent action if available; otherwise honestly mark no current action.
4. **Leave a return trigger.** For a real deadline or another person's dependency, set a reminder you will see or a return point. A reminder only prompts you to read the resume note; it does not perform the task. Without a deadline, a note placed with the material may be enough. Do not rely on remembering a long open list.
5. **Read it as a stranger would.** From the note alone, can you find the current material, last verified point, and first action? Add an exact name, object location, version, or next step if missing, without turning it into a diary. Put materials away, release shared space, and pause any still-used equipment under its own instructions.

Fast version: “[Task]: current material at [location/version]; checked through [point]; next [action]; waiting for [person/input].” If leaving suddenly, those four fields beat an unfinished perfect note.

### Success

The resume note and material exist and can be found. It separates verified, unfinished, and externally awaited work, points to one doable next action, and has a return point where needed. On return you must check whether reality changed; an old note is not permanently authoritative. The note is not task completion, successful handover, or a guarantee of instant concentration.

### Common errors and recovery

- **Only “continue tomorrow” was written:** Add exact material location, last verified point, and first action.
- **Changes were unsaved before closing:** Save and verify reopening first. If already lost, use a separate unsaved-text recovery process; do not pretend the note contains missing work.
- **Three files are named final:** Identify the one current file and why older versions remain; give it a clear name within your control if needed.
- **You await someone but wrote “finish step 3 next”:** Mark the actual dependency and next check point instead of a currently impossible action.
- **A public sticky note exposes private material:** Move it to an authorized place and reduce it to non-sensitive cues.

### Assumptions, alternatives, and side effects

This covers ordinary pausable work, not dangerous equipment procedures or medical, legal, or financial decisions. Paper, accessible voice notes, or digital text can all work if you can find and identify the version later; do not force tiny handwriting on someone who needs another format. When interruption is sudden, a four-field note is better than a perfect record never finished. Environment, material, and deadlines can change, so the resume point is a map into the task, not a permanent guarantee of reality.
