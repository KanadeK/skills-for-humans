## 中文

你有原创草图却在不断换颜色、画面主次开始混乱时，先选少量有明确角色的色样。目标是主色、辅助色、最暗与最亮位置可以区分，缩小到实际屏幕观看尺寸仍读得清。颜色数量是本次画面的约束，不是所有画必须遵守的配色理论；不以软件色号保证跨设备完全一致。

### 准备与输入

保存草图，在空白角落或单独测试层留一块色样区。写出画面主体需要的颜色角色，而不先搜集大量别人作品配色；若参考图获准，可观察明暗关系，但本次色板仍由你组合和决定。

### 执行

1. 用颜色选择器先定一个主体基色和一个背景/辅助色，在色样层各画小块并标明角色。
2. 为阴影和高光补一深一浅，查看它们与基色的明度差，而非只看色相是否漂亮。
3. 缩小到实际展示大小并临时以灰度感受亮暗层级；若主体与背景糊成一片，改明度或面积。
4. 记录采用的几个色样，删除多余尝试，把色板留在隐藏参考层或可重复找到的面板，再保存工程。

### 完成、常见问题与恢复

画面已有一组少量且有用途的色样；主体与背景在目标观看尺寸仍能分开。

- **全画面同亮度：** 先调整最深/最浅两个角色，再看颜色。
- **色样混进成稿：** 把试样移到独立隐藏层。
- **不同屏幕偏色：** 以当前设备作普通审阅，不宣称色彩校准。

### 假设与边界

只建立一张普通屏幕插画的初始色板，不保证色觉可及性达标、专业印刷或品牌色一致；重要发布还需外部检查。

## English

Use this when an original sketch is being slowed by endless color changes. Finish with a small set of swatches assigned to base, support, darkest and lightest roles that remain readable at the intended screen size. The number of hues is a working constraint for this picture, not a universal theory or a guarantee of cross-device color matching.

### Preparation and inputs

Save the sketch and reserve a test layer or corner for swatches. Name the roles the subject needs before collecting many borrowed palettes. A permitted reference can inform value relationships, but the chosen combination remains your own decision.

### Execution

1. Use the color selector to choose a subject base and supporting/background color, painting named swatches on the test layer.
2. Add one darker and one lighter role, comparing value differences with the base rather than hue appeal alone.
3. Zoom to target display size and judge light-dark hierarchy; if subject and background merge, change value or occupied area.
4. Record the chosen swatches, discard extras, keep the palette in a hidden reference layer or retrievable panel, then save.

### Success, common problems, and recovery

A small role-based swatch set exists, and subject and background remain distinguishable at intended viewing size.

- **Flat value range:** Adjust darkest and lightest roles before changing all hues.
- **Swatches in art:** Move the swatches to a separate hidden layer.
- **Display shifts:** Treat this as ordinary local review rather than calibrated proof.

### Assumptions and limits

This creates an initial palette for one ordinary screen illustration, not certified color accessibility, print proofing or brand-color fidelity. Important publication needs separate review.
