## 中文

当你已有一台电脑，要买普通打印机、摄像头或扫描仪，并需要它完成**一个明确功能**时，加载这份 Skill。目标是购前把候选准确型号对系统版本、处理器架构、接口以及该功能的软件支持逐项核到现有电脑上；不下载驱动、不安装软件、不登录账号，也不把“接口插得上”当功能证明。

### 准备与输入

从电脑现有设置/可靠资料记下操作系统名称、版本、处理器架构和可用接口，不需要把设备序列号或账号信息上传给卖家。写一项必需结果，例如“从这台电脑扫描成文件”或“以需要的清晰度开视频会”。找候选准确型号及**该功能**的官方系统要求、驱动/系统内置支持范围、连接方式和必要软件；“同品牌近似型号”不能代替。

### 执行

1. **先确定必用功能。** 区分“能被电脑认出”和“扫描、双面打印、摄像头高分辨率等目标功能可用”。只需基本打印时，不必把厂商所有附加 App 当必需；目标功能确实依赖软件时则不能忽略。
2. **核系统与架构。** 在准确型号官方支持表中找到当前操作系统版本，以及 Intel/ARM 等架构限制。旧手册写“支持 Windows”没有覆盖所有当前 Windows 版本或处理器；没有明确支持就保留未知。
3. **核连接路径。** 看现有接口或网络与外设要求是否匹配，USB 接头形状和速率、无线方式或同一网络条件都按准确资料核对。线缆能力可另行检查；接口匹配不能补上缺失的软件支持。
4. **核功能级支持。** 某些系统能自动识别基本打印，却需要其他驱动/软件才能用扫描或特殊设置。找制造商对该操作系统的功能表、系统内置功能说明或兼容性公告；不要把“安装程序存在”当目标功能能运行的证据。
5. **输出结果。** 记录“现有电脑系统/架构/接口 → 外设准确型号 → 必用功能的当前支持路径 → 支持、仅基本功能、未确认或不支持”。有一个关键版本或软件条件缺失时暂停购买，向制造商问清；不运行来源不明的驱动来试。

### 成功与停止

你能指出目标功能在现有电脑的准确系统与连接方式上有当前官方资料支持，才完成购前兼容核对。若功能依赖新账号、云服务、付费许可或个人数据授权，先单独弄清并决定是否接受；本 Skill 不代你开通。硬件损坏、系统改装或高风险设备停止普通外设流程。

### 常见报错与补救

- **“即插即用”被当成所有功能可用：** 分开查基本识别与扫描、视频规格等你真正需要的功能。
- **同系列别的型号有驱动，就替候选盖章：** 回到准确型号及系统版本的支持页。
- **系统名称一样，架构不同：** 核处理器类型与安装/内置支持说明；有些安装器的限制不同。
- **资料页面打不开或字太小：** 使用可读官方支持页、请可信的人读回型号/版本；不能取得资料时记未确认，不下载陌生工具填空。

### 假设、替代与现实副作用

这份流程只做普通电脑外设购前适配，不负责安装、驱动排障、账号或网络配置。软件支持会改变，购买前读当前官方页面并记录日期；语言和销售地区不能自动推出系统兼容。你可能发现基本功能已经足够，也可能选择不用安装附加软件的型号。

## English

Load this Skill before buying an ordinary printer, webcam, or scanner for a computer you already own when you need **one named function**. The outcome is a pre-purchase match between the exact peripheral and your current OS version, processor architecture, connection, and feature support. It does not download drivers, install software, sign into an account, or treat a fitting plug as functional proof.

### Preparation and inputs

From current settings or reliable records, note the computer's OS, version, processor architecture, and available ports. You need not share its serial number or account details with a seller. Name the required result, such as “scan a file from this computer” or “join calls at my needed video quality.” Find the exact candidate model and the official requirements for **that feature**, including driver or built-in OS support, connection, and essential software. A nearby model from the same brand does not stand in for it.

### Execution

1. **Name the essential feature.** Separate “the computer detects it” from scanning, duplex printing, high-resolution video, or another actual goal. If basic printing is enough, not every maker app is required. If the goal depends on software, that dependency cannot be ignored.
2. **Check OS and architecture.** Find your present OS version and Intel/ARM or other architecture in the exact model's current support table. An old “supports Windows” statement does not cover every present version or processor. Keep undocumented support unknown.
3. **Check the connection path.** Compare the existing port or network with the peripheral's requirements: USB shape and speed, wireless method, or same-network condition as relevant. Cable capability can be checked separately; a matching connector cannot supply absent software support.
4. **Check feature-level support.** Some systems detect a printer for basic output while scanning or special settings need other support. Use the maker's feature table, built-in OS guidance, or compatibility notice for this OS. An installer existing somewhere is not evidence that your target function works.
5. **Record the decision.** Write “current OS/architecture/port → exact peripheral → current support path for the essential feature → supported, basic-only, unconfirmed, or unsupported.” Pause when a key version or software condition is missing and ask the maker. Do not test with an untrusted driver.

### Success and stop conditions

You finish when current official information supports the named feature on the exact computer system and connection. If the feature needs a new account, cloud service, paid licence, or personal-data permission, inspect that separately and decide whether to accept it; this Skill signs up for nothing. Hardware damage, modified systems, and high-risk devices leave this ordinary peripheral route.

### Common errors and recovery

- **“Plug and play” was read as every feature works:** Check basic detection and the scan/video/print function you actually need separately.
- **Another model in the series has a driver, so this one must:** Return to exact model and OS version support.
- **The OS name matches but the architecture differs:** Check processor type and installer or built-in support; some installers have different limits.
- **The support page is inaccessible or tiny:** Use a readable official page or ask someone trusted to read back model and version. Keep the result unconfirmed rather than downloading a stranger's tool.

### Assumptions, alternatives, and side effects

This covers ordinary pre-purchase computer peripherals, not installation, driver debugging, accounts, or network setup. Software support can change; read current official information near purchase and record its date. Language and selling region do not imply OS compatibility. You may find the built-in basic feature enough or choose a model that needs no extra app.
