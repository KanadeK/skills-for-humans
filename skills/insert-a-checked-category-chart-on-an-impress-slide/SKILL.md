## 中文

你已有少量可信的类别次数汇总，想在 Impress 一张页上用简单图形比较它们时使用本篇。成果是图表里的类别标签和数值都来自自己的汇总，示例数据完全移除，放映预览中标题与最大/最小柱可读。不能把插入后的默认示例图直接当成果。

### 准备与输入

保存 ODP 副本，列出每个类别的确切次数和单位，确认不含总计行或空白类别。想好柱状图是否比表格更清楚，页上留足空间。记下最大和最小值作核对；若图像和文字已经拥挤，应先调整页面而非叠加。

### 执行

1. 在目标页使用 Insert > Chart，进入图表编辑模式，认出默认示例内容。
2. 把示例类别与数值完全换成已核汇总，选普通二维比较形式并设清楚标签。
3. 退出编辑，在放映预览比对各柱、最大最小和标题，不让图挡住正文。
4. 保存重开再核没有示例名称残留；错误时重进数据编辑，不手工改柱图形。

### 完成、常见问题与恢复

图表只显示自己的类别和次数，数值与源汇总一致，演示页可读。

- **仍有示例数据：** 重进编辑删掉全部示例项。
- **图像遮文字：** 移动或缩小图，不牺牲可读字体。
- **总计成最大柱：** 从来源移除总计行。

### 假设与边界

只呈现已核的小型类别比较，不生成统计结论或实时数据连接。你负责来源、单位与许可；图表默认样式不保证所有屏幕可读。

## English

Use this Skill with a few trustworthy category counts that a single Impress slide should compare visually. Finish with categories and values taken from your checked summary, all sample chart data removed, and title plus largest/smallest bars readable in show preview. The default example chart is not a finished result.

### Preparation and inputs

Save an ODP copy and list exact category counts and unit, excluding total row and blank categories. Decide whether a column chart clarifies more than a table and reserve slide space. Note largest/smallest values; fix crowding before adding an object.

### Execution

1. Use Insert > Chart on target slide, enter chart edit mode and identify default sample data.
2. Replace every sample category and number with checked summary, choose a plain 2D comparison and clear labels.
3. Exit edit mode and compare bars, largest/smallest and title in show preview without covering text.
4. Save/reopen and check no sample names remain; correct underlying chart data rather than hand-drawing bars.

### Success, common problems, and recovery

Chart shows only your categories and counts, agrees with source summary and reads well on slide.

- **Sample data remain:** Reopen chart data and replace all samples.
- **Chart covers text:** Move or resize chart without tiny type.
- **Total becomes a bar:** Exclude grand-total row.

### Assumptions and limits

This presents a small checked category comparison, not statistical inference or live data linkage. You own source, unit and permission; default styling is no display guarantee.
