## 中文

你已会一个**四根弦都可以弹且各自清楚**的和弦，想把一次扫弦改成逐弦指弹时使用本篇。练习结果是按 G→C→E→A 顺序逐根轻拨，四声可区分，整组重复两次而不误碰邻弦。这里的输出是分解和弦的可控顺序，不是读单弦 tab，也不要求新和弦或完整伴奏。

### 准备与输入

确认琴已调好、和弦图没有 X 弦，并先逐根检查四弦能响。正常持琴方向从脸侧到地面侧是 G、C、E、A；低 G 改变音高但不改变这些弦名和本组顺序。用指腹轻拨，不用指甲用力钩弦。若手形僵硬或手痛，暂停。

### 执行

1. **指出将弹的弦。** 手指不拨时依次指认 G、C、E、A，口数四拍，一拍一根；不要从实际音高猜 G 的位置。
2. **做第一组。** 保持已会的和弦形，在四个慢拍上逐根轻拨 G→C→E→A。每拨一下确认只响目标弦，手指随后离开弦的振动区域。
3. **检查并微调。** 如果某声闷，先检查按弦手而非一口气换整套指弹法；若两弦同响，减少拨弦手横向扫过距离。一次只改一个接触点。
4. **再做一组。** 第二组仍按同样顺序与慢拍，结束后明确收手。你能说出四弦顺序并听见八个有序音才算完整；某弦持续不响就记录它。

### 完成、常见问题与恢复

两组各四声按 G、C、E、A 发出且互相可辨，或指出具体误碰/闷住的一弦。

- **把 G 当最低音找错弦：** 依琴的物理位置与弦名，不依高低音排序。
- **两弦一起响：** 缩小拨弦动作，每次只接触一弦。
- **和弦弦音先天不清：** 返回单和弦检查再分解。
- **手疼或僵：** 停止，休息后选择更舒适姿势。

### 假设与边界

该已知和弦允许四弦全响；有 X 弦的图不能直接使用此顺序。你负责核查实际音；本篇不规定特定左右手分指法，也不复制歌曲指弹谱。

## English

Use this Skill with **one already-clear chord that permits all four strings** when you want to replace a sweep with individual plucks. Finish by sounding G→C→E→A as four distinguishable notes, then repeat the whole order once without accidentally striking neighbours. The output is controlled arpeggio order, not one-string tab, a new chord or a complete accompaniment.

### Preparation and inputs

Tune the instrument, confirm the chord chart has no X string, and test all four individually first. In playing position the strings from face to floor are G, C, E, A. Low G changes pitch but not these string names or this exercise's order. Pluck lightly with finger pads rather than hooking hard with nails. Pause if the hand stiffens or hurts.

### Execution

1. **Point to the strings.** Without plucking, identify G, C, E, A in order and count four slow beats, one per string. Do not locate G by assuming it is the lowest pitch.
2. **Play the first group.** Hold the known chord and pluck G→C→E→A on four slow beats. After each pluck, check that only the target sounded and move the picking finger clear.
3. **Check and adjust.** If a note is dull, inspect the fretting hand first rather than changing the entire picking method. If two strings sound, make the picking motion narrower. Change one contact detail at a time.
4. **Play a second group.** Repeat the same order and slow count, then stop deliberately. Close when you can name the order and hear eight ordered notes. Record any string that stays muted.

### Success, common problems, and recovery

Two groups of G, C, E, A sound separately and recognizably, or you name the specific muted or accidentally struck string.

- **G mistaken for the lowest string:** Use physical position and names, not pitch order.
- **Two strings sound together:** Narrow the motion to one string.
- **Chord itself is unclear:** Return to individual chord-string checks.
- **Hand stiff or painful:** Stop, rest and choose a comfortable position.

### Assumptions and limits

The known chord allows all four strings; an X-marked diagram cannot use this order unchanged. You check the actual sound. This does not prescribe one right/left hand finger assignment or copy a song's fingerpicking score.
