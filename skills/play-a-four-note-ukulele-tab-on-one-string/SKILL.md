## 中文

你有已调好的标准 gCEA 尤克里里，想第一次把**一个原创的一弦四音 tab**读成真实声音时使用本篇。示例只用第一弦 A：`A|0-2-3-2`，每个数字按自己数的一拍演奏；0 是空弦，其余数字是第几品。完成时四音顺序和拍数可复述、可重弹。不同于和弦图，它一次只选择一根弦与一个音，暂不要求唱谱或演奏歌曲。

### 准备与输入

确认第一弦 A 与琴的调弦一致。将 `0-2-3-2` 写在纸上，数字之间画四个等距拍点；这是本篇原创短句，不从歌曲抄取。检查第 2、3 品是否舒适可及，按弦指尖应在目标金属品丝靠琴头一侧近处。手痛则停止或减小练习范围。

### 执行

1. **把数字指给实物。** 指认 0 为空弦、2 为第二品、3 为第三品；每个数字都在同一 A 弦，不要误当作第 2/3 根弦。
2. **慢速逐音拨。** 口数 1、2、3、4，在四拍上依次拨 A 空弦、A 第二品、A 第三品、A 第二品。每次只让这一根弦发声，手指换位留足时间。
3. **检查顺序与清晰度。** 拨完立即对照纸上四数字。若第 3 音不清，只单独试第 3 品，再从首音重来；若节拍乱，降低口数速度，不改变数字。
4. **重弹并结束。** 再完整弹一遍并在第 4 音后收手。能说出“空、二、三、二”且两遍顺序一致才收口；若琴调弦不匹配，记录不能照谱使用。

### 完成、常见问题与恢复

两遍 `0-2-3-2` 在同一 A 弦按四拍发声，或准确指出未能完成的数字/拍点。tab 数字显示品位，本例拍长由我们明确自定，不能假定任何 tab 自带节奏。

- **把数字误当弦号：** 回到 `A|` 弦标签重认。
- **第三品打品：** 调整指尖与压力，先试单音。
- **四音越弹越快：** 放慢口数，每个数字只占一个拍点。
- **不是 gCEA 琴：** 查本琴调弦与谱的适配，不硬用音名。

### 假设与边界

本篇只使用自己编写的四音例子。你控制节拍；tab 一般还需另附节奏信息，本例自行规定等拍。版权曲谱、完整乐句与正式识谱不在范围。

## English

Use this Skill with a tuned standard gCEA ukulele to read **one original four-note tab on one string** into sound. The tiny example uses only the first A string: `A|0-2-3-2`. Play each number on one self-counted beat; 0 means open and other numbers name frets. Finish when you can say, play and replay the four notes in order. Unlike a chord diagram, this selects one string and one note at a time, without requiring a song.

### Preparation and inputs

Confirm the first string is A under your tuning. Write `0-2-3-2` with four equally spaced count marks; this is an original exercise, not copied from a song. Check that frets two and three are comfortably reachable. Place fingertips just behind metal frets on the headstock side. Stop or reduce the exercise if the hand hurts.

### Execution

1. **Map numbers to the instrument.** Point to 0 as open, 2 as second fret and 3 as third fret. All are on the same A string; they are not string numbers.
2. **Pluck slowly.** Count 1, 2, 3, 4 aloud. On those counts play open A, second-fret A, third-fret A, second-fret A. Sound only that string and leave enough time to move.
3. **Check order and clarity.** Compare the played order with the four written numbers. If note three is unclear, isolate third fret before restarting; if the beat drifts, slow the count without changing the numbers.
4. **Replay and end.** Play the whole line once more and stop after note four. Close when you can say “open, two, three, two” and both runs match. If the instrument's tuning differs, record the mismatch rather than asserting the same pitches.

### Success, common problems, and recovery

Two runs of `0-2-3-2` sound on the same A string over four counts, or you name the failed note/count. Tab numbers show frets; rhythm must be stated separately, as it is in this example.

- **Numbers mistaken for strings:** Return to the `A|` string label.
- **Third fret buzzes:** Adjust fingertip and pressure, then test that note alone.
- **Line speeds up:** Slow the spoken count, one number per beat.
- **Instrument not gCEA:** Check its tuning against the tab instead of forcing pitch names.

### Assumptions and limits

This uses only a self-written four-note example. You control the count. Ordinary tab often needs separate rhythm notation; this example explicitly assigns equal beats. Copyrighted scores and full music reading are outside scope.
