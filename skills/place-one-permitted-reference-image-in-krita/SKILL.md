## 中文

你需要观察自有物件的比例或配色，却不想把照片本身粘进原创绘画时，用参考图工具。结果是参考图在画布旁可看见、位置与缩放合适，绘画层里没有它的像素；文件如何随工程保存也已明确。参考图的使用许可和来源要由你确认，能看到网上图片并不等于有权照搬。

### 准备与输入

先确认图像是自己拍摄或获明确允许，排除含未经同意肖像和隐私的照片。保存 .kra，检查参考文件所在目录会不会搬动；若要交接工程，准备考虑嵌入，若文件大且会更新，考虑稳定路径链接。

### 执行

1. 选 Reference Images Tool，通过 Add Reference Image 加入那一张文件，确认它作为参考对象而非普通绘画层出现。
2. 调整大小、位置及需要的透明度，让参考可观察又不挡主体；保持原始宽高比以免误导比例。
3. 在工具选项核嵌入 .kra 或链接外部文件的存储方式；记下来源和许可及外部路径的移动风险。
4. 保存、重开工程检查参考图仍可见，再隐藏参考图核正式绘画层没有被照片像素污染。

### 完成、常见问题与恢复

重开后参考图按预期显示，正式画层仍是原创笔画，许可和存储模式可追溯。

- **重开后缺图：** 查外部链接路径是否移动，必要时重新指向原文件或改嵌入。
- **照片压住画面：** 移到画布边或暂时隐藏，不在图层里橡皮擦。
- **比例看着怪：** 恢复保持宽高比，重新观察主体。

### 假设与边界

本篇只管理一张合法参考图，不授权复制他人作品、人物形象或商标，也不把参考图自动转成原创绘画。

## English

Use this when observing an owned object or licensed source for proportion or color without pasting the photograph into the artwork itself. Finish with a visible, conveniently placed reference that is not paint-layer content, and an explicit choice about how the reference is stored with the project. Availability online is not permission to copy.

### Preparation and inputs

Confirm ownership or express permission and avoid unconsented likenesses or private information. Save the .kra and consider whether the source file path will move. Embedding may suit a small vital reference; a stable link may suit a large changing one.

### Execution

1. Use Reference Images Tool and Add Reference Image for the single file, confirming it appears as a reference object rather than an ordinary paint layer.
2. Resize, position and if needed lower opacity so it remains visible without covering the subject; keep aspect ratio so observation is not distorted.
3. Choose embed in .kra or link to external file in tool options; note source, permission and any path-move risk.
4. Save and reopen to verify the reference persists; hide references and confirm the artwork layers do not contain the photo pixels.

### Success, common problems, and recovery

The reference remains available after reopening, painted layers still contain original strokes, and source rights plus storage mode are traceable.

- **Missing after reopen:** Check whether the linked file moved, relink to the real source or choose embedding.
- **Covers art:** Move it aside or temporarily hide references rather than erasing on paint layers.
- **Distorted proportion:** Restore aspect ratio before using it for observation.

### Assumptions and limits

This manages one lawful reference, not permission to copy someone else's artwork, likeness or mark, and it never turns a source photo into original painting automatically.
