## 中文

你要建议修改 Writer 文稿中的一个词句，但审阅者仍需看到原文和改动时使用本篇。成果是一条可见的插入/删除修订记录，位置正确、原文可追溯，操作完成后记录状态被按需要关闭。它是审阅提案，不把提出改动等同于已获接受或实际发布。

### 准备与输入

保存 ODT 副本，记下目标句原文、拟改文和改动理由，确认文件不是别人尚未授权的私稿。打开修订显示设置，先看是否已有未决修订，避免把他人的改动误认作自己的。只圈定一处文字，不顺手批量改。

### 执行

1. 在 Edit > Track Changes > Record 启用记录，并确认 Show 可见。
2. 只选目标文字，键入拟改内容，观察删除原文和插入新文的标记。
3. 核前后句通顺、原字与新字都能在修订视图中辨认，理由可另记批注但不虚构事实。
4. 保存重开抽查修订仍在，并明确关掉或保留 Record 以免后续普通打字无意留痕。

### 完成、常见问题与恢复

一处改动以可见修订存在、原文可找、未被提前接受，记录开关状态明确。

- **看不到删除原文：** 核 Show 是否关闭或改动时未启用 Record。
- **整段都变修订：** 撤销并缩小选择范围。
- **后续所有字也留痕：** 结束后按需关 Record。

### 假设与边界

只记录一处文字修订，不裁决是否采纳。你负责内容与权限；本篇不代表共享审阅、正式签核或出版。

## English

Use this Skill when suggesting one wording change in a Writer draft while a reviewer needs both old and proposed text. Finish with a visible insertion/deletion tracked change at the right place, original wording still reviewable, and recording state left intentionally on or off. This is a review proposal, not acceptance or publication.

### Preparation and inputs

Save an ODT copy and note original phrase, proposed phrase and reason. Confirm you may edit this draft. Turn on change visibility and inspect existing pending edits so another person's proposal is not mistaken for yours. Target one passage, not a batch.

### Execution

1. Enable Edit > Track Changes > Record and make sure Show displays marks.
2. Replace only target wording and inspect marked deletion and insertion.
3. Check surrounding sentence reads and both old/new wording remain identifiable; add a factual comment if needed.
4. Save and reopen to confirm edit persists, then deliberately turn Record off or leave it on by choice.

### Success, common problems, and recovery

One change remains visibly tracked, original wording can be found, it was not silently accepted, and recording state is known.

- **Old wording invisible:** Check Show and whether Record was on during edit.
- **Whole paragraph marked:** Undo and narrow selection.
- **Later typing tracked too:** Turn Record off when done if appropriate.

### Assumptions and limits

This records one wording proposal, not its acceptance. You own content and permission; no shared review, formal approval or publication is implied.
