## 中文

你已有三到五页基本定稿的 Impress 短段，希望知道自己实际讲述是否顺畅时使用本篇。成果是一遍按顺序走完的私人预演、实际耗时与至少一处停顿或确认“无明显卡点”的记录。单屏时可在放映前看 Notes，双屏才使用 Presenter Console；不把装置条件当作人人都有。

### 准备与输入

保存 ODP 副本，选明确起止页、可用计时器和每页一两条自己写的备注。先核 Notes 不含不应暴露的信息，再决定是否使用双屏讲者视图。关掉会自动跳页的设置或明确知道它们的作用；不是请真实观众验收。

### 执行

1. 从预定起页启动放映，口头讲出每页一句核心意思，计时从第一句到最后一句。
2. 按既定顺序主动前进，双屏可看 Presenter Console 备注；单屏用事前记忆或纸卡，不在主屏露出 Notes。
3. 记录实际总时间和一处需要回看、跳页或读不清的具体页号，不为缩短时间而删事实。
4. 结束后回 ODP 核是否因预演误改定时或放映状态，保存观察记录供下次单项修订。

### 完成、常见问题与恢复

一段完整私人预演有实际时间和具体卡点/无卡点记录，主屏没有泄露讲者备注。

- **备注出现在主屏：** 停下核显示模式或改用纸卡。
- **自动跳页：** 核 Advance Slide 设置后再预演。
- **忘记录时：** 重做一遍，不猜总时长。

### 假设与边界

这只测本人短预演，不代表真实观众理解或现场投影成功。你负责讲述内容；不自动保存定时作为发布设置。

## English

Use this Skill with a mostly ready three-to-five-slide Impress segment to learn whether your own spoken sequence flows. Finish with one private full run, measured duration and one stumble or an honest 'no obvious pause' record. On one display, read Notes before running; Presenter Console is available only with dual displays. Do not assume everyone's setup has it.

### Preparation and inputs

Save an ODP copy, choose start/end slides, a timer and one or two self-written notes per slide. Check Notes for material that should not be disclosed, then decide whether dual-display presenter view is available. Disable unintended auto-advance or know its effect. This is not an audience acceptance test.

### Execution

1. Start at chosen slide, speak each slide's main point aloud, and time first to last sentence.
2. Advance in order. With dual display use Presenter Console notes; with one display use pre-read notes or a paper cue, not Notes on main screen.
3. Record total time and a specific slide number for a stumble, backtrack or unreadable item, without deleting facts merely to fit time.
4. After the run, inspect ODP for accidental timing/state changes and keep the observation for one focused next edit.

### Success, common problems, and recovery

A complete private run has actual duration and a specific stumble or none noted, with speaker notes not exposed on main screen.

- **Notes on main screen:** Stop and inspect display mode or use paper cue.
- **Auto-advance:** Check Advance Slide before retry.
- **Forgot timer:** Repeat instead of guessing duration.

### Assumptions and limits

This tests only your short private rehearsal, not audience comprehension or live projection. You own content; it does not automatically set publishing timing.
