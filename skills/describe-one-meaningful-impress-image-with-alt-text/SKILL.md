## 中文

你有一张承担信息的 Impress 图片，想让不能看图的读者得到它对本页论点的关键贡献时使用本篇。成果是对象的替代文字写明该贡献，简短且不重复整页标题；这不同于裁切画面或可见图注。不要把图片文件名、“一张照片”或未经证实的推断当成描述。

### 准备与输入

保存 ODP 副本，看图片及周围文字，先用一句话说清它是示例、证据还是步骤图。若图片纯装饰，考虑适当装饰标记而不硬编说明。确认选的是正确对象，若图中信息太多应先决定哪些细节是理解必需。

### 执行

1. 选中目标图片，打开 Format > Alt Text 或本机等价对象属性入口。
2. 写一条针对本页语境的短说明；复杂图只补真正必要的细节，不臆测画外因果。
3. 不看图只读标题、正文和替代文字，检查主旨能否理解且不显得机械重复。
4. 保存重开再选图核文字仍在正确对象；导出 PDF 时另核标签设置，不能凭此一步宣称可及。

### 完成、常见问题与恢复

一张有意义图片具备准确、适量的非视觉说明，保存重开仍可定位；纯装饰图不伪造信息。

- **只写文件名：** 改成此页图像传达的事实。
- **说明与图不符：** 回实际图像核词，不推断。
- **写到错对象：** 重选正确图并核属性。

### 假设与边界

此篇只处理一张图片对象，不证明整个演示稿可及、PDF 标记有效或现场辅助技术体验。你负责图像内容与许可。

## English

Use this Skill when an Impress image carries meaning and someone who cannot see it needs the image's contribution to the slide's point. Finish with concise alternative text on the object describing that contribution without repeating the entire title. This differs from cropping or a visible caption. Avoid a filename, 'a photo' or unsupported inference.

### Preparation and inputs

Save an ODP copy and inspect image plus surrounding words. State whether it is an example, evidence or step diagram. For pure decoration, use an appropriate decorative treatment rather than inventing meaning. Select the right object and choose only details essential to understand its role.

### Execution

1. Select target image and open Format > Alt Text or equivalent object property.
2. Write a short context-specific statement; add only necessary detail for complex images without imagined causal claims.
3. Read title, body and alt text without looking at image; check understanding and avoid mechanical repetition.
4. Save/reopen and check text remains on correct object; inspect PDF tagging separately before claiming accessibility.

### Success, common problems, and recovery

One meaningful image has accurate proportionate non-visual description on the right object after reopen; decorative imagery is not given invented meaning.

- **Only filename:** Describe the point conveyed here.
- **Description mismatches:** Inspect image and remove inference.
- **Wrong object:** Select correct image and check property.

### Assumptions and limits

This handles one image object, not whole-deck accessibility, PDF tag validity or live assistive-technology experience. You own image content and permission.
