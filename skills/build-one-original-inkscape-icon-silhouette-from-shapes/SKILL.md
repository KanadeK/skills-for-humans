## 中文

你有一张自己画的图标草图，需要先把主体轮廓建成可缩放的矢量对象时，用少量基本形状拼出主形。成果是在不看细节和颜色的情况下，缩到目标尺寸仍认得出含义；它不是照着现有品牌图标描边。原生形状保留专用手柄，先不要急着全部转成路径。

### 准备与输入

保存 SVG，写一句图标要表达的普通物件或动作，并标出最重要的外轮廓和留白。挑最多几种能表达大形的矩形、圆或椭圆，不因工具很多就增加与识别无关的星形和旋涡。

### 执行

1. 在画页中心用基本形状工具建立主体和必要附属块，维持草图的总体比例。
2. 逐件调控制柄和尺寸，使交叠关系清楚，仍保留对象独立可编辑。
3. 临时统一涂成单色并缩到目标观看尺寸，核外形是否还能读出预期主题。
4. 删去不能帮助识别的块，保存并重开确认主体仍由少量对象组成。

### 完成、常见问题与恢复

一枚少量形状构成的原创图标有清晰主体轮廓，在预期小尺寸仍可辨。

- **细节太多：** 隐藏细节只看外轮廓，删除不增识别的块。
- **交叠看不清：** 暂换对比色或调整前后次序，再恢复单色测试。
- **像已有商标：** 停下重画自己的主题和轮廓，不靠改色避让。

### 假设与边界

只做普通原创图标的几何主形，不构成商标检索、可及性认证或美术验收。

## English

Use this when a self-drawn icon sketch needs a scalable main silhouette. Build it from a few editable basic shapes, then test whether the meaning survives at the target small size even before color or detail. Do not trace an existing brand mark. Native shapes keep useful handles, so avoid converting everything to paths prematurely.

### Preparation and inputs

Save the SVG and write one sentence describing the ordinary object or action represented. Identify essential outer silhouette and negative space. Pick only a few rectangles, circles or ellipses that express it, rather than adding decorative shapes because tools are available.

### Execution

1. Build the body and necessary supporting masses near page center using basic shape tools, keeping sketch proportions.
2. Adjust shape handles and dimensions so overlaps are clear while objects remain individually editable.
3. Temporarily make the shapes one color and zoom to target size to test whether the silhouette still conveys the subject.
4. Remove shapes that do not aid recognition, save and reopen to confirm the body remains a small set of editable objects.

### Success, common problems, and recovery

A small set of original vector shapes forms a clear icon silhouette recognizable at its intended reduced size.

- **Too many details:** Hide details and remove masses that do not improve recognition.
- **Overlap unclear:** Use temporary contrast or stacking change, then repeat single-color test.
- **Looks like a brand:** Redesign subject and silhouette rather than merely recoloring.

### Assumptions and limits

This builds one ordinary original icon body; it is not trademark clearance, accessibility certification or art-direction approval.
