## 中文

你要让读者在页面上知道一张图片是什么，并能用“图 2”之类的编号指它时使用本篇。成果是图片旁有可见图注，类别与编号和前后图一致，图注文字不夸大图片内容。这不同于替代文字：图注给所有看页的人读，不能代替给非视觉读者的对象描述。

### 准备与输入

保存 ODT 副本，确认图片自有或获准、图中事实已核。查看文稿已有图注的类别名称、号码和标点，记下上一张及下一张图。拟一条简短可见说明，说明画面与正文关系，不复制不必要的文件路径。

### 执行

1. 选中目标图片，用右键 Insert Caption 或 Insert > Caption 打开图注对话框。
2. 选择与文稿一致的 Figure 类别及自动编号方式，填入简短图注文字。
3. 检查图注紧随正确图片，和前后图的编号连贯，正文没有被包进图注框。
4. 保存重开，再核图片与图注在同页或合理相邻；若编号冲突，查类别设置而非手改数字。

### 完成、常见问题与恢复

目标图有准确的可见图注，编号与同类别图顺序协调，原文无损。

- **编号重复：** 核是否手打或用了另一类别。
- **图注跟错图：** 撤销，先选准对象再插。
- **导出后图注移位：** 回 ODT 核锚点并在导出文件复查。

### 假设与边界

图注只管理可见说明与编号，不保证复杂跨格式导出位置，也不代替图片替代文字。你决定内容是否可公开。

## English

Use this Skill when page readers need a visible label for one image and a managed figure number they can cite. Finish with a visible caption beside the image, category and sequence consistent with neighbouring figures, and wording that does not overclaim the image. This differs from alternative text: captions are visible on the page and do not replace object descriptions for non-visual readers.

### Preparation and inputs

Save an ODT copy and confirm image permission and visible facts. Inspect existing figure captions for category, numbering and punctuation; note previous and next figures. Draft one short visible explanation connecting the image to prose, without an unnecessary file path.

### Execution

1. Select target image and open Insert Caption from its context menu or Insert menu.
2. Choose the document's Figure category and managed numbering form, then enter short caption wording.
3. Check caption stays with correct image, numbering matches neighbours and body text did not enter caption frame.
4. Save and reopen; check image and caption stay together or sensibly adjacent. For numbering conflict, inspect category setting instead of typing digits.

### Success, common problems, and recovery

Target image has an accurate visible caption whose managed number fits the category sequence, with prose intact.

- **Number repeats:** Check typed number or different category.
- **Caption on wrong image:** Undo and select correct object.
- **Caption shifts on export:** Check ODT anchor and exported page.

### Assumptions and limits

A caption manages visible explanation and numbering, not cross-format layout guarantees or alternative text. You decide disclosure permission.
