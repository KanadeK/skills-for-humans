## 中文

当一批你有权保管的纸张已经决定要保存，却只能凭记忆找具体抽屉或纸袋时加载。你要建立**纸张组 → 有名文件夹 → 实际物理位置**的单一索引，并亲自按它找回一次。这里不决定哪些法律/税务/医疗资料必须留、留多久，也不把私密内容上传公共服务。

### 准备与输入

先把仍待行动、可处理或归属不明的纸分开；只对已明确保存的纸建索引。确认谁有权查看它们，选一个能实际保管的本地位置与普通文件夹/信封。隐私较高的纸用中性标签和有权者可控制的存放方式，不在外侧写证件号码、病情、密码或完整私人事项。

### 执行

1. **按未来会怎样寻找分组。** 选少量本人能理解的组名，例如“设备说明”“预约往来”“购买凭证”；真正属于别人的纸不混入。太宽的“重要文件”找不到，太细到每张都新建文件夹也难维护。
2. **给文件夹一个稳定名字与位置。** 在文件夹外写中性名称或短码，在收纳位置写可复现的路径，如“书架 A 盒 2 / 文件夹 3”。选择能支撑纸张且不过满的文件夹，不折损原件来迎合过小的袋子；归档容器本身不要堵住常用通道。
3. **写唯一的本地索引。** 一行只需“会搜索的中性词 → 文件夹名/码 → 存放位置 → 有权保管人”；必要时加年月或简短内容范围。不要另外制作一份常年不同步的公开“完整目录”，也不把每页私密详情抄入索引。
4. **让实物和索引互相回读。** 从索引找到文件夹，再用文件夹标签回到同一行；同名组有两个位置时补区分码。纸张临时借出时在原位置留中性借出标记和接手人，不能把空文件夹仍写成“完整在盒里”。
5. **做一次真实找回试验。** 暂时不靠记忆，让你自己或有权者给一个普通查找词，按索引走到实物，再放回同一处。找不到就改组名/路径并复测；只有“记得大概在哪儿”不算完成。

### 完成与停止

每组已确认保存的纸有物理文件夹和一个当前真实位置，授权的人用索引可找回并归位；私密信息没有无谓写在外面。文件归属、保存必要性或保管权限不明时先暂停那一组，不能为了目录整齐替他人作处分决定。

### 常见报错与补救

- **三个文件夹都叫“杂项”：** 按下次可能搜索的用途给不同中性名或编号，再重试查找。
- **索引写的是旧抽屉：** 按实际位置更正，移动纸夹时同步维护；不保留两个互相冲突的权威位置。
- **夹子太满，纸边外露：** 分成两个可辨文件夹并更新索引，不硬塞或裁剪原件。
- **外侧标签泄露私事：** 换中性代码，将对应关系留在只有授权者可看的索引里。
- **有人借走一份原件：** 原位置留借出状态与接手人；归还后实见再改回在位。

### 假设、替代与副作用

这只处理普通纸质文件的定位，不给保留年限、真实性或办事资格结论。家庭、居住空间和可用文件夹不同，可用纸本索引、信封和现有盒，不需购置“档案级”材料；长期珍贵或脆弱原件可按专业保存意见处理。视力/阅读不便时用大字、触觉或经授权的人读回标签，仍要保持隐私。副作用是“第二个抽屉吧”有了可以复走的路线。

## English

Load this Skill when papers you are allowed to keep have already been selected for preservation, but finding them still depends on remembering a drawer or bag. Build **one route from a search term to a named folder to its real physical place**, then use it to retrieve something once. This does not decide legal, tax or medical retention, set a retention period or upload private contents to a public service.

### Preparation and inputs

Keep still-actionable, disposable or ownership-uncertain papers separate. Index only what is already clearly meant to be kept. Confirm who may see them and select a real local storage spot plus ordinary folders or envelopes. Use neutral outer labels and access controlled by the right holder for more private material; never write ID numbers, health detail, passwords or complete private matters outside.

### Execution

1. **Group by how you will search later.** Choose a few names you understand, such as “item guides,” “appointment correspondence” or “purchase records.” Do not mix another person's papers into yours. “Important documents” can be too broad, while a new folder for every page can be hard to maintain.
2. **Give folders stable names and places.** Put a neutral name or short code outside and a reproducible location in your storage note, such as “Shelf A / Box 2 / Folder 3.” Use a folder that supports the paper without overfilling; do not damage an original to fit a small envelope. The container should not block an ordinary route.
3. **Keep one private local index.** A line needs only “neutral search word → folder name/code → physical place → authorised holder,” with a month or short range if useful. Do not create another public full catalogue that will drift, or transcribe every private page into the index.
4. **Read object and index back to each other.** From one line, find the folder; from its label, find the same line. Give two folders with one name distinct codes. If an original is temporarily loaned, leave a neutral loan-out note and recipient at its place; an empty folder is not “fully present.”
5. **Test real retrieval.** Without relying on memory, give yourself or an authorised person an ordinary search term, follow the index to the paper and put it back. If that fails, revise category or path and test again. “I know roughly where it is” is not completion.

### Success and stop

Every confirmed keep group has a folder and one current real position, and an authorised person can retrieve and return it using the index without needless private information on the outside. Pause any group whose ownership, retention decision or access authority remains unknown. A tidy directory does not grant you control of another person's papers.

### Common errors and recovery

- **Three folders are all named “miscellaneous”:** Give distinct neutral uses or codes and test retrieval again.
- **The index names an old drawer:** Correct to observed location whenever you move the folder. Do not preserve two conflicting authoritative locations.
- **A folder is too full and pages stick out:** Divide it into two identifiable folders and update the index. Do not cut or force the original.
- **An outside label reveals private matters:** Use a neutral code and keep the mapping with the authorised person's index.
- **Someone borrows an original:** Leave a loan-out state and recipient at its place; mark it present again only after observing its return.

### Assumptions, alternatives, and side effects

This locates ordinary paper; it does not judge retention length, authenticity or service eligibility. Homes and supplies differ: paper index, envelopes and existing boxes can work without archival-grade purchases. Ask a preservation specialist for valuable or fragile originals if needed. Large print, tactile codes or an authorised readback can support access while protecting privacy. “Maybe the second drawer” gets a route you can actually walk.
