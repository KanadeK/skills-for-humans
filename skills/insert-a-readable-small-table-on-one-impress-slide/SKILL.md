## 中文

你要在一张 Impress 页上并列比较少量已核事实，想用真实表格而不是空格对齐时使用本篇。成果是一张有标题行、字段逐格对应、放映预览中文字可读的小表；数据多到挤压文字时应缩减或拆页。它是呈现事实，不执行 Calc 统计或验证来源真伪。

### 准备与输入

保存 ODP 副本，先在纸上列出列名与条目，算好包含标题的行数和列数，选择不暴露私人资料的值。检查页上给表的可用面积及标题位置，避免用整页细格子塞满观众视野。记下首末数据供逐格核对。

### 执行

1. 在目标页使用 Insert > Table 输入实际行列数，确认表在页内出现。
2. 填写标题行及少量数据，从左到右逐格核字段关系，不让空格代替列结构。
3. 在放映预览检查最长单元格、末行和列名可读、无截断，必要时减少内容。
4. 保存重开，与原记录抽查数值及表外标题未变。

### 完成、常见问题与恢复

表的行列与计划一致、表头和数据对齐，投影预览可读且原值无误。

- **表太密：** 删减到关键行或另拆页。
- **值错列：** 按表头逐格复核调整。
- **末行被截：** 调整对象尺寸或内容，不盲缩微字。

### 假设与边界

只呈现少量已核事实，不处理大型数据表或统计。你负责原值与现场可读性；不同屏幕可能显示不同。

## English

Use this Skill when one Impress slide must compare a few checked facts in columns rather than simulated spacing. Finish with a real table with labels, facts in correct cells and readable type in show preview. If many rows force tiny text, reduce or split content. This presents facts, not Calc analysis or proof of source truth.

### Preparation and inputs

Save an ODP copy, write headers and entries on paper, and count rows including header and columns. Use non-private facts. Check available slide space and title position; do not fill the whole screen with tiny cells. Note first and last data values for integrity checks.

### Execution

1. Use Insert > Table with actual row and column counts and confirm it appears on target slide.
2. Fill headers and few data cells, checking column meaning left to right rather than spaces.
3. Preview longest cell, last row and labels for readable size and no clipping; reduce content if needed.
4. Save/reopen and compare sampled values with source and unchanged slide title.

### Success, common problems, and recovery

Table rows/columns match plan, labels align with facts, show preview is readable and source values agree.

- **Table too dense:** Keep key rows or split slide.
- **Value under wrong label:** Recheck cell by cell.
- **Last row clipped:** Adjust object or content, not tiny type.

### Assumptions and limits

This presents a few checked facts, not large datasets or statistics. You own source accuracy and live readability; displays may differ.
