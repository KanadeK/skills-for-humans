## 中文

当你为已有相机、录音机或其他普通设备买 SD/microSD 卡，想知道大容量或“高速”卡能否满足实际录制时，加载这份 Skill。目标是确认设备支持该卡家族、外形、容量范围，以及录制任务所需的**持续写入**等级；这里不格式化卡、不转移或删除数据。

### 准备与输入

记下设备准确型号与所用卡槽，找其说明书对 SD、SDHC、SDXC 或 SDUC 的支持、全尺寸或 microSD 外形、允许容量范围和录制模式需要的速度等级。写下你真实要录的照片、音频或视频模式；没有确定模式时先按你会使用的最高模式查。准备候选卡包装/制造商资料上的家族、容量、外形、速度等级及完整型号。

### 执行

1. **先核主机标准。** 按准确设备说明书确认支持的 SD 家族，而不是只看卡槽形状。较大的容量可能属于主机不认识的后续家族；SD 协会的兼容表帮助读标准，准确设备手册仍要核对。
2. **核外形与容量。** 全尺寸 SD 与 microSD 尺寸不同；若要靠转接卡，先确认设备允许这种用法。再对照设备列出的最小/最大容量和任何单独的卡型限制。能插入不代表能够识别全部容量。
3. **核写入任务。** 视频等连续录制需要稳定写入。找设备对所选录制模式要求的 Speed Class、UHS Speed Class 或 Video Speed Class，再比候选卡同体系的标记；包装只写峰值读取速度时，不能用它证明持续写入达标。
4. **确认整条能力链。** 即使卡上等级更高，设备端接口也可能限制实际速度；只要所需模式有相互支持的标准与等级即可，不因“数字最大”跳过兼容核对。
5. **留下可复查结论。** 记录“设备/录制模式 → 支持的家族/外形/容量/最低写入等级 → 候选卡对应标记 → 满足、不满足或未确认”。任一关键项缺失时找准确设备手册或制造商答复，不凭旧卡外观猜。

### 成功与停止

你能把候选卡的家族、物理规格、容量和与录制模式相符的持续写入等级逐项对应到设备要求，才完成购前核对。设备资料过时、卡槽损坏或需要格式化旧卡验证时停止推断；不要为了购物实验而清空现有数据。

### 常见报错与补救

- **旧设备有 SD 槽就买最大 SDXC/SDUC：** 查准确设备支持的家族；尺寸相似不能越过标准兼容表。
- **卡上写很高的 MB/s，就当视频稳录：** 找所需录制模式对应的最低持续写入等级，按同一种标记体系核对。
- **只比较容量，忘记外形或转接：** 检查全尺寸/microSD 卡槽以及制造商是否允许转接。
- **小字或符号看不清：** 放大制造商规格、请可信的人读回完整标记；不能辨认时保留“未确认”，不让相似图标替代证据。

### 假设、替代与现实副作用

这份流程针对普通消费设备购前选卡；实际可录时长还取决于文件格式和录制设置，不在这里给统一数字。地区营销称呼不同，标准标记以卡和设备的准确资料为准。没有网络时可用纸质说明书；找不到设备要求就延后购买，不拿唯一一张存有资料的旧卡做破坏性实验。

## English

Load this Skill before buying an SD or microSD card for a camera, recorder, or another everyday device when a larger or “faster” card seems attractive. Your outcome is a match across card family, physical form, supported capacity, and the **sustained-write** class needed for your recording job. This Skill does not format cards or move or delete data.

### Preparation and inputs

Record the exact device model and slot. Find its manual's support for SD, SDHC, SDXC, or SDUC, full-size or microSD form, allowed capacity, and speed-class requirement for recording modes. Name the photo, audio, or video mode you will actually use; if undecided, check the most demanding mode you expect to use. Get the candidate card's family, capacity, form factor, speed-class marks, and complete product identifier.

### Execution

1. **Check the host standard first.** Use the exact device guide to confirm which SD families it supports, rather than judging from slot shape. A higher capacity may belong to a newer family the host cannot read. The SD Association matrix explains standards, but the device manual remains the check for your model.
2. **Check form and capacity.** Full-size SD and microSD have different dimensions. If an adapter is planned, first check whether the maker supports it. Compare the host's allowed capacity range and any separate card-type limit. A card fitting physically does not prove all its capacity is recognized.
3. **Check the write task.** Continuous video recording needs sustained writing. Find the device's required Speed Class, UHS Speed Class, or Video Speed Class for the chosen mode and compare the candidate's corresponding mark. An advertised peak read speed alone cannot establish sustained-write performance.
4. **Check the whole capability path.** A higher-rated card can still be limited by the host interface. You need a mutually supported standard and sufficient class for the actual mode, not the largest printed number.
5. **Record the decision.** Write “device/mode → supported family/form/capacity/minimum write class → candidate marks → supported, unsupported, or unconfirmed.” Find the exact manual or maker answer for missing fields rather than guessing from an old card's appearance.

### Success and stop conditions

You finish when the card's family, size, capacity, and sustained-write class each map to the device's requirements for your recording mode. Stop guessing if the guide is obsolete, the slot is damaged, or checking would require formatting an old card. Do not erase existing data to run a shopping experiment.

### Common errors and recovery

- **An old device has an SD slot, so any large SDXC/SDUC card must work:** Check its supported family; matching shape does not bypass the standards matrix.
- **A large MB/s number was treated as reliable video writing:** Find the recording mode's minimum sustained-write class and compare the same mark system.
- **Capacity was compared without form factor or adapter:** Check the full-size/microSD slot and whether the maker permits an adapter.
- **Marks are too small or similar:** Enlarge the maker's specifications or ask someone trusted to read back the full symbols. An unreadable mark remains unconfirmed.

### Assumptions, alternatives, and side effects

This covers pre-purchase cards for ordinary consumer devices. Actual recording time depends on format and settings, so no universal duration is promised. Marketing names vary by market; use the exact standard marks and device guide. A paper manual works offline. When the host requirement is missing, wait rather than using the only card holding your data for a destructive experiment.

### Sources

- [SD Association: Speed classes for recording](https://www.sdcard.org/consumers/about-sd-memory-card-choices/speed-class-standards-for-video-recording/) — a speed class represents minimum sequential write performance under defined conditions; a peak read-speed claim is not a substitute.
