## 中文

你已有完好、明确按标准 **gCEA** 调弦的高 G 四弦尤克里里，练习前想确认四根空弦音高时使用本篇。结果是 G、C、E、A 各自经调音器稳定读到目标，或因弦、旋钮、琴型不明而停止。低 G、男中音等变体不能照抄本篇的音区；先查本琴说明。无需买新调音器，已有夹式/手机调音器即可。

### 准备与输入

在安静、安全的座位拿稳琴，确认琴弦无断裂、严重磨损或异常松脱；调音器选择尤克里里或可显示音名的色彩模式。把琴抱在正常演奏方向：从靠近脸的一侧到地面侧依次为第四到第一弦 g、C、E、A。确认每根弦连到哪个旋钮，别凭相邻位置猜。

### 执行

1. **只弹一根空弦。** 不按品，轻拨第四弦，读调音器显示的音名和偏高/偏低；先确认它识别的是该弦，而非环境声。
2. **小幅转对应旋钮。** 先观察转向是否让读数靠近目标；每次只转少量并重新拨弦。接近目标时更慢，阻力、弦快断的感觉或音名跳得不合理就停止。
3. **逐根核对。** 按 g、C、E、A 次序检查其余三根，每次先确认旋钮与弦的对应。偏差很大或琴型不是标准高 G 时查本琴资料，不强拉到网页上的通用音高。
4. **再巡一遍。** 轻拨四根空弦重读；新弦可能回落，必要时按本琴说明再次微调。把无法稳定调上的一根记下，转合适店员或维修人员，不自行调结构件。

### 完成、常见问题与恢复

四根空弦都独立读到该琴的目标音名并再次核过；否则明确哪根无法确认。调音器一次闪过绿色不等于全部调好。

- **读数乱跳：** 让旁边声音停下，重新轻拨一根弦。
- **转了旋钮却是另一根变音：** 停下，逐弦追线到旋钮再继续。
- **琴型或高/低 G 不清：** 查制造商标签/说明，不强迫匹配。
- **弦有损伤或旋钮打滑：** 停止调音并求助合适维修。

### 假设与边界

只面向现有、完好、高 G 标准调弦的常见四弦琴。你决定实际调弦；本篇不教换弦、琴桥/琴颈调整或移调。弦材和尺寸以本琴说明为准。

## English

Use this Skill before practice when you own an intact four-string **standard high-G gCEA** ukulele. Finish with each open G, C, E and A string reading its target steadily on a tuner, or stop if strings, pegs or instrument type are uncertain. Low-G and baritone variants may need another range or tuning; check your instrument's instructions. An existing clip-on or phone tuner is enough.

### Preparation and inputs

Sit safely in a quiet space and inspect for broken, badly worn or unusually loose strings. Set an existing tuner to ukulele or a note-displaying chromatic mode. In playing position, the strings from face side to floor side are fourth through first: g, C, E, A. Trace each string to its actual peg before turning it.

### Execution

1. **Pluck one open string.** Do not fret it. Gently sound the fourth string and read the note and high/low indication. Confirm the tuner hears this string rather than room sound.
2. **Turn only its peg a little.** Observe whether a small move brings the reading toward target; re-pluck after each move. Slow down near target. Stop for unusual resistance, a string near breaking, or an implausible jump.
3. **Check the remaining three.** Work through g, C, E, A, confirming each peg/string link first. For a large mismatch or a nonstandard instrument, check its own guidance rather than pulling hard toward a generic web target.
4. **Recheck all four.** Pluck each open string again; new strings may drift and need small model-approved adjustments. Record any string that will not hold and seek an appropriate shop or repair person instead of adjusting structural parts.

### Success, common problems, and recovery

Each open string independently reads the instrument's target note on a second pass, or the uncertain string is named. A single momentary green flash is not a full tuning check.

- **Reading jumps:** Reduce nearby noise and sound only one string.
- **A different string changes:** Stop and trace strings to pegs.
- **Model or high/low G uncertain:** Consult maker labels and guidance.
- **Damaged string or slipping peg:** Stop and obtain suitable repair help.

### Assumptions and limits

This covers an intact common four-string high-G instrument. You control the tuning. It does not teach restringing, bridge/neck work or alternate tuning. The actual maker's string and size guidance governs.
