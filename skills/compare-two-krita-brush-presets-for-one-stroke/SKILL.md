## 中文

你准备画清晰轮廓或大面积铺色，却还不知道现有预设哪支更可控时，先做很短的同条件样线。完成结果是基于边缘、粗细、透明度和手感选择一支，而不是迷失在下载更多画笔里。选用预设只是本张画的工具决定，不是对艺术风格的永久承诺。

### 准备与输入

新建不影响正式画面的测试层或独立小画布，设同一颜色与相近笔径，记录这次要画的线段长度和速度。触控笔与鼠标都可测试，但按实际输入方式比较；若压感没有工作，先只比较当前真实可用表现。

### 执行

1. 从 Brush Presets 选第一支，画一条直向和一条转弯样线，观察起笔、收笔与断续。
2. 撤销或在旁边用第二支按同一颜色、笔径和动作再画，避免把不同条件误当预设差异。
3. 放大看边缘、锯齿、透明叠笔，再缩回正常观看尺寸，判断哪支更适合这一个用途。
4. 记下预设名称、临时笔径和选择理由；删去测试层或保留在隐藏参考层，正式画前切回目标图层。

### 完成、常见问题与恢复

两种预设在可比条件下留下样线，所选预设能完成本次线条目的且测试痕迹不污染成稿。

- **笔径差太多：** 调到接近视觉粗细再比。
- **测试写在底稿上：** 撤销或移到独立测试层，核正式层未被涂改。
- **只有压感不同：** 按当前设备真实输入比较，不推断驱动故障。

### 假设与边界

只在已有预设中为一项笔触做选择，不改画笔引擎、不安装资源，也不解决设备驱动。画风判断仍由画者决定。

## English

Use this when you have one concrete stroke task, such as a clean contour or broad block-in, and two plausible installed presets. Finish with a small side-by-side test and a reasoned choice based on edge, width, opacity and control. Choosing a preset for this drawing does not require downloading brushes or committing to a permanent style.

### Preparation and inputs

Use a separate test layer or small canvas, the same color and comparable size, and define the stroke length and speed you need. Test with the input device you will actually draw with. If pressure is unavailable, compare the real behavior rather than assuming a tablet feature.

### Execution

1. Choose the first preset in Brush Presets and draw a straight and curved sample, observing starts, ends and interruptions.
2. Draw beside it with the second preset using matching color, size and motion so changing conditions are not mistaken for preset behavior.
3. Inspect edges, jaggies and overlap up close, then return to normal viewing size and decide which serves this specific purpose.
4. Record preset name, working size and reason; remove or hide the test layer and switch back to the intended artwork layer.

### Success, common problems, and recovery

Comparable samples show which preset meets the present stroke task, and the test marks do not contaminate the final artwork.

- **Size mismatch:** Match visible width before judging the presets.
- **Marks on artwork:** Undo or move tests to a separate layer and inspect the real artwork.
- **Pressure difference:** Judge the actual input behavior without diagnosing a driver.

### Assumptions and limits

This picks among installed presets for one stroke job. It does not edit brush engines, install resources or troubleshoot drivers. Artistic style remains your decision.
