## 中文

你已为自己的短旋律决定一组简单和弦，需要在谱上告诉伴奏者从哪一拍换和弦时，输入和弦符号。成果是几个符号各自对准目标小节或拍位，名称与本人和声计划相符。软件把字符排漂亮不代表它替你验证和声是否好听；如果和声尚未想好，先做创作决定。

### 准备与输入

保存谱面，在纸上列每个和弦根音、性质和生效小节；只用自己确知含义的基本记法。确认谱面当前是需要标和弦的声部；若只是唱名或分析罗马数字，本篇不把它们混作普通字母和弦。

### 执行

1. 选第一个应换和弦的音符或休止，启动 Chord Symbol 输入并键入计划中的名称。
2. 按节拍或下一个目标位置推进，逐个录入其余和弦，不在没有变化的每个音上重复写同名。
3. 退出输入，核符号被解析为可读名称、升降号正确且水平位置对准变化拍。
4. 从头读和声计划与谱面，短播仅作辅助核错，保存重开；若符号和旋律冲突，先回创作计划裁决。

### 完成、常见问题与恢复

每个和弦符号的名称与位置符合本人计划，谱面可读且没有把文字解析成功误认成音乐正确。

- **符号没正确解析：** 核根音/升降号输入语法，别直接粘贴特殊字形。
- **换和弦拍错：** 重选对应音或休止并移回锚点。
- **符号过密：** 只保留实际和声变化点。

### 假设与边界

只录入本人已定的简单字母和弦，不自动配和声、不提供专业和弦分析或爵士复杂记号指导。

## English

Use this when you have chosen a simple harmonic plan for your own melody and want a player to see where each chord begins. Finish with a few chord symbols aligned to planned beats or bars and matching your written choices. Automatic parsing of text into attractive symbols is not harmonic analysis or approval of the progression.

### Preparation and inputs

Save and list each intended chord root, quality and start bar. Use basic syntax you understand. Select the staff where symbols should appear; Roman-numeral analysis and lyric syllables are different text systems, not interchangeable with simple letter chord names.

### Execution

1. Select the note or rest at the first harmonic change, enter Chord Symbol mode and type the planned name.
2. Advance to each actual change point and enter remaining symbols without repeating the same label on every note.
3. Exit entry and inspect parsed spelling, accidentals and alignment to the harmonic change beat.
4. Read the plan against the score from the start, using brief playback only to reveal mistakes, then save and reopen; resolve harmonic conflict in the plan.

### Success, common problems, and recovery

Each chord symbol matches your planned name and placement, with readable notation and no claim that parsing proves musical correctness.

- **Parsing failed:** Inspect root and accidental syntax instead of pasting a special glyph.
- **Wrong beat:** Reanchor to the correct note or rest.
- **Too crowded:** Keep labels only at genuine changes.

### Assumptions and limits

This records self-chosen simple letter chords, not automatic harmonization, professional analysis or complex jazz-symbol guidance.
