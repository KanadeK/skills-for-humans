## 中文

你已有四小节自己写的音高与时值草案，要把它们写进软件而不让默认休止符或鼠标点位改掉旋律时，用这个输入流程。结果是每个小节拍数正确、音高与草案对应，播放只用来辅助发现输入错误。软件能排版和合成音，不会判断旋律是否动听或原创性。

### 准备与输入

先在纸上或个人记录中逐小节列音名与时值，核每小节总时值符合拍号。保存空谱并找到第一小节第一拍；若不识英文字母音名或当前谱号，就先核对转换，避免连续输错。

### 执行

1. 选择第一拍位置，进入音符输入模式，先设第一音时值再输入音名。
2. 按草案逐音输入四小节；每换时值都明确核工具栏显示，不让上一个音的时值无意延续。
3. 退出输入模式，逐小节读音名、音区和拍数；发现节奏或八度错误时只改对应音。
4. 短播四小节并对照草案核节奏轮廓，保存 .mscz；若听觉与记谱冲突，先回草案确认意图。

### 完成、常见问题与恢复

四个小节的每一音都可和原创计划逐一对应，小节时值完整且原稿可继续编辑。

- **音都成同一时值：** 回对应小节重设时值再输入。
- **音区跳太远：** 核所选音符八度，按原计划修而非凭声音猜。
- **多出音或缺拍：** 逐拍核小节，不用拖谱面元素遮住错误。

### 假设与边界

只输入四小节原创独奏旋律，不代写旋律、和声、歌词或演奏建议。合成播放与真实乐器音色和呼吸不同。

## English

Use this when you have a four-measure melody plan of your own and want the entered score to match it rather than inheriting accidental defaults. Finish with correct beat totals and pitches in each bar. Playback can reveal entry mistakes, but notation software cannot judge whether a tune is good or original.

### Preparation and inputs

List each bar's pitch names and durations in a personal plan and verify each total against the meter. Save the empty score and locate the first beat of bar one. If note-letter names or the clef are unfamiliar, check them before entering a long wrong run.

### Execution

1. Select the first beat, enter note input mode and choose duration before typing the first pitch.
2. Enter the four bars note by note. At each duration change, inspect the toolbar rather than carrying forward the previous value accidentally.
3. Exit input mode and read each bar's pitch, octave and beat total, correcting only the mistaken notes.
4. Play the four bars briefly against the plan for rhythmic contour and save the .mscz; if sound and notation conflict, confirm the intended plan first.

### Success, common problems, and recovery

Each note in four measures maps to the self-authored plan, bar durations are complete and the master remains editable.

- **Durations all same:** Reenter affected notes with explicit durations.
- **Wrong octave:** Inspect the selected pitch and adjust octave from the plan.
- **Beat mismatch:** Audit the bar beat by beat rather than hiding errors with layout moves.

### Assumptions and limits

This enters four bars of original solo melody. It does not compose, harmonize, write lyrics or advise performance. Synthesized playback differs from a real musician.
