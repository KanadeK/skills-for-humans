## 中文

你的一段原创旋律有一个音要短促、强调或保持饱满，需要把发音方式写在音符上时，只处理这一处。成果是记号属于正确音符、视觉位置清楚，与乐句连奏或力度的含义不冲突。别因为符号看起来漂亮就叠加多个记号；先说清要改变的是时长感、起音还是持续。

### 准备与输入

保存谱面，在个人草案中写目标音所在小节与拍位、想要的演奏变化。查所选记号的常规意义和当前乐器是否适用，核目标音是否已经有连奏线或其他记号，避免造成相反指令。

### 执行

1. 单选目标音，从 Articulations 调色板或音符工具栏添加一个需要的记号。
2. 核符号在该音符上方或下方且与旁边音区分，避免拖动成只在视觉上贴近却锚到别处。
3. 短播目标音及前后音，记录播放能否帮助发现错误；播放差异弱时仍以记谱意义判断。
4. 保存重开再看记号，若意思与原计划不符，删去并重选，不靠解释文字圆场。

### 完成、常见问题与恢复

一个常规发音记号明确附着于计划音，邻音无误加，读谱意图一致。

- **加到多个音：** 撤销并只选一个目标音。
- **与连奏冲突：** 回原意决定该音是否真应断开。
- **试听没差：** 查音源表现，不把记谱符号当自动音效保证。

### 假设与边界

只加一处常见发音记号，不代替老师指导、真实演奏技巧或专业声部规则。

## English

Use this when one note in your original phrase needs a short, accented or sustained manner of attack. Finish with one readable articulation attached to the correct note and compatible with the phrase's other marks. Do not stack symbols for decoration; decide whether the intended change concerns length, attack or sustain.

### Preparation and inputs

Save and write the target bar, beat and desired performance difference. Check the conventional meaning of the symbol and whether it suits the instrument. Inspect any existing slur or marking that could conflict.

### Execution

1. Select only the target note and add one intended marking from the Articulations palette or note toolbar.
2. Inspect placement above or below that note and ensure it is not merely visually near another anchor.
3. Play the note with neighbors and note whether playback reveals an error; when a sound library barely changes it, rely on the notated meaning.
4. Save and reopen. If the symbol conveys the wrong meaning, remove it and choose the right one instead of explaining away a wrong mark.

### Success, common problems, and recovery

A conventional articulation attaches to the planned note only and communicates the intended attack or length.

- **Multiple notes marked:** Undo and select a single target.
- **Conflict with slur:** Return to the musical plan and decide whether this note should separate.
- **No audible change:** Inspect library response without treating the notation as guaranteed audio processing.

### Assumptions and limits

This adds one common articulation; it does not replace instrumental instruction, live technique or professional section-specific practice.
