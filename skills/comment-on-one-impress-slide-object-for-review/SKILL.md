## 中文

你在 Impress 一张页里发现一张图、一个数字或一处链接需要核实，但不应立刻改内容时使用本篇。成果是页内有一条具体、可回答的批注标记贴近对象，原对象未变；批注不是对他人发送消息，也不表示已经完成核查。不要只写“有问题”而不说要查什么。

### 准备与输入

保存 ODP 副本，选准页和对象，想清楚待核的问题与可信证据入口。注意批注会留在 ODP，不能放不应共享的私密资料。若整页都需要审阅，也要在文字里标明具体元素，免得以后找不到。

### 执行

1. 在 Normal 视图目标页使用 Insert > Comment，确认产生的标记属于此页。
2. 写明对象与需要核对的事实，保留原数字或图片不擅自替换。
3. 把小标记移动到对象附近，检查它不遮挡观众要读的主要内容。
4. 保存重开，确认批注和对象仍能对应；误放页时撤销并重做。

### 完成、常见问题与恢复

准确对象旁有可回答批注，页内容未改，重开仍可找到。

- **批注在错页：** 删除误批注并在目标页重插。
- **问题太含糊：** 补对象名称与证据需求。
- **标记盖住图：** 移到邻近空白。

### 假设与边界

本篇只留下本地审阅问题，不发通知或做结论。你负责后续查证及 ODP 分享范围；多人协作不在本篇。

## English

Use this Skill when an image, number or link on one Impress slide needs checking but should not be changed yet. Finish with a specific answerable comment marker near that object and source content intact. A comment is not a message sent to another person or evidence that the review is complete. Avoid a vague 'problem' note.

### Preparation and inputs

Save an ODP copy, identify slide and object and write a concrete question with evidence path. Comments remain in ODP, so do not include private material that should not be shared. Even for a whole-slide concern, name the exact element in the comment.

### Execution

1. Use Insert > Comment in Normal view of target slide and confirm the marker belongs to it.
2. Name the object and fact to check, keeping original number or image unchanged.
3. Move small marker near object and check it does not obscure important visible content.
4. Save and reopen, confirming comment-object relationship; undo wrong-slide placement.

### Success, common problems, and recovery

An answerable comment is locatable near the intended object, content unchanged and persistent after reopen.

- **Comment on wrong slide:** Remove mistaken comment and insert on target.
- **Question too vague:** Name object and evidence needed.
- **Marker covers visual:** Move into nearby whitespace.

### Assumptions and limits

This leaves one local review question, no notification or conclusion. You own later fact-checking and ODP sharing; multi-author collaboration is outside scope.
