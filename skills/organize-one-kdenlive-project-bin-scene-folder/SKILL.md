## 中文

你已导入几段同一场景的自有素材，Project Bin 混在其它片段里难找，想用一个有意义的虚拟文件夹归拢时使用本篇。成果是该场景素材能在箱内按名称找回，原文件路径和已排上的时间线片段不受影响。它整理工程视图，不是 Windows 文件夹搬迁或清理源媒体。

### 准备与输入

保存工程，写下该场景真实名称和应归入的几段素材清单，确认哪些素材被其它场景共用。项目箱文件夹是虚拟组织，不能把它当成已在磁盘上搬运文件。先核时间线已有片段数量作对照。

### 执行

1. 在 Project Bin 用 Create Folder 建一层场景文件夹，名称简短可识别。
2. 只把属于该场景的素材项归入文件夹，核未误纳别的内容。
3. 展开/收起文件夹找回两段样本，核 Clip Monitor 预览及原路径仍有效。
4. 检查已有时间线位置/内容未变，保存重开工程再看文件夹。

### 完成、常见问题与恢复

场景素材在项目箱可找、源文件不搬动、时间线未乱。

- **误删文件夹：** 从工程备份恢复，不删源文件。
- **素材放错场景：** 按预览移回合适位置。
- **以为硬盘也归档：** 区分虚拟文件夹与实际路径。

### 假设与边界

只整理一个场景的项目箱，不保证跨工程素材管理或文件系统备份。你负责分类语义。

## English

Use this Skill when a few owned clips from one scene are lost among other Project Bin items and a meaningful virtual folder would help. Finish with those assets retrievable by folder name, source paths and already placed timeline clips intact. This organizes project view, not a Windows filesystem move or source cleanup.

### Preparation and inputs

Save project, write a real scene name and clip list, noting any asset shared by other scenes. Bin folders are virtual organization, not proof of disk relocation. Note already-used timeline clip count before changes.

### Execution

1. Use Create Folder in Project Bin for one short identifiable scene folder.
2. Place only matching bin items in folder and check exclusions.
3. Open/collapse folder to find two samples and verify Clip Monitor and source paths.
4. Check existing timeline clips unchanged, save/reopen and inspect folder.

### Success, common problems, and recovery

Scene assets are findable in bin with no source move or timeline disruption.

- **Folder deleted:** Restore project, not source files.
- **Clip misfiled:** Use preview and correct bin grouping.
- **Disk assumed sorted:** Separate virtual and real paths.

### Assumptions and limits

This organizes one scene's bin, not cross-project asset management or filesystem backup. You choose grouping meaning.
