## 中文

当你自己制作的普通文档或帖子里有一张图片，而不看图的人可能错过重要信息或按钮作用时，加载这份 Skill。目标是**给这张图片在当前内容中的作用提供准确文字替代**；不是把“图片”二字、文件名或猜测的人物情绪塞进描述。文档的标题和列表导航是另一件事。

只处理你有权编辑的低敏感普通内容。正式无障碍合规、医疗图像、身份证件、机密截图和需要专业解释的数据图不在此流程里；图中有私人信息时先决定是否应放图，而不靠替代文字掩盖风险。

### 准备与输入

先问：读者为什么需要这张图？若删掉它，正文失去什么信息或动作？查看周围已写的标题、说明和链接，避免重复同一句话。选择当前发布平台确实提供的“替代文字”“图片说明”或正文位置；不要假定每个软件都会把文件名读给人听成有用信息。

### 执行

1. **判断图片在这里的角色。** 它可能传递信息、充当链接/按钮、只是装饰，或承载需要更长解释的图表。相同照片在不同文章里作用可能不同，按这次读者任务判断，不按图片类型机械套模板。
2. **信息图写最有用的事实。** 用一两句说明读者需要知道的内容与关系，例如“入口台阶旁有一条左侧坡道，通往同一扇门”。只写你知道或图中能确认的内容；看不清的字、人名、原因和情绪不要猜。
3. **功能图写动作或目标。** 图片若是可点的按钮或链接，说明点击后做什么，例如“打开路线说明”；“蓝色箭头图标”不足以说明功能。若旁边已有同样清楚的真实文字，避免重复朗读。
4. **装饰图按平台提供的方法标记。** 纯装饰且不传递额外内容时，使用编辑器的“标记为装饰”或对应空替代文字方式；不要用一段无关细节占据朗读时间。若平台没有这些选项，检查能否通过正文结构避免图片成为唯一信息入口。
5. **复杂图把要点写在正文附近。** 趋势图、流程图或密集截图不能靠一句“图表”交代。用邻近文字说出读者必须知道的趋势、步骤或关键数值，并让短替代文字指向这段说明；若你无法准确读出数据，停下核对来源，不编造数值。
6. **保存后从非视觉路径检查。** 重新打开内容，查看替代文字是否真的保存、是否位于正确图片，并用可用朗读/屏幕阅读器模式或不看图只读文字的方式走一遍。若平台把替代文字丢失，改用可见正文说明或换支持该功能的发布方式；别声称已完成。

### 完成条件

不看图的人从实际可读的文字中仍能知道图片为这段内容贡献的信息或功能；纯装饰不会重复打断阅读。描述符合图和上下文，保存后仍在。若平台能力、图像内容或真实读者体验未验证，明确保留待确认，不把“填了一个字段”当作无障碍验收。

### 常见报错与补救

- **替代文字只写“照片/截图”：** 重问图为何在此，改写与读者下一步有关的事实或动作。
- **描述和正文一模一样：** 若正文已完整传达，可按平台规则标装饰或缩短重复内容；别让人听两遍同一句话。
- **自动生成的描述猜错了：** 按你实际看见和核对的信息修正；不知道的人物身份或情绪不要当事实写入。
- **图表太复杂：** 在正文补关键趋势、分类或数值来源，短说明只概括并指向那里；无可靠数据就停止发布精确结论。
- **平台不提供替代文字：** 把关键信息写进相邻正文，并检查不看图仍能理解；必要时换可编辑的发布方式。

### 假设、替代与现实副作用

这是一份普通内容的作者侧补充，不是正式 WCAG 认证。各平台的替代文字、装饰标记和朗读呈现不同，以实际界面为准。可以请使用非视觉阅读方式的人反馈，但别把他们当免费验收工具；先自己完成可做的检查。写好说明后你可能发现这张图其实没有承担任何信息，保留它也无妨，只要不让它挡路。

## English

Load this Skill when an image in an ordinary document or post you authored conveys information or an action that a nonvisual reader could miss. **Provide an accurate text alternative for what this image does in this context.** “Image,” a filename, or a guess about someone's feelings is not useful description. Document heading and list navigation is a separate task.

Edit only ordinary low-sensitivity content you are allowed to publish. Formal accessibility certification, medical images, identity documents, confidential screenshots, and specialist interpretation of data charts are outside this flow. If the image contains private information, first decide whether it should be included at all; alt text cannot hide that risk.

### Preparation and inputs

Ask why the reader needs this image. What information or action would disappear if you removed it? Read the nearby heading, explanation, and link text so you do not repeat the same sentence. Find the actual platform's alt-text, image-description, or body-text field. Do not expect a filename spoken aloud by software to be useful meaning.

### Execution

1. **Decide the image's role here.** It may inform, act as a link or button, decorate, or carry a chart that needs longer explanation. The same photo can play different roles in different posts. Decide from this reader task, not an automatic template for its file type.
2. **For an informative image, write the useful fact.** One or two sentences can convey needed content and relationship, such as “A ramp to the left of the entrance steps reaches the same door.” State only what you know or can confirm in the image. Do not guess unclear text, names, causes, or emotions.
3. **For a functional image, name the action.** If it is a clickable button or link, say what activating it does, such as “Open route details.” “Blue arrow icon” alone does not convey the function. If adjacent real text already says it clearly, avoid repeated speech.
4. **Mark a decorative image in the platform's way.** If it adds no new information, use the editor's decorative control or equivalent empty alternative text where supported. Do not fill reading time with irrelevant detail. If no such option exists, check whether the surrounding body can carry any needed meaning without the picture.
5. **Put complex meaning beside the image.** A trend chart, flow diagram, or dense screenshot cannot be explained by “chart.” Write the essential trends, steps, or figures in nearby body text and use a brief image alternative to point toward that explanation. If you cannot verify the data, stop and check the source rather than inventing figures.
6. **Check after saving through a nonvisual route.** Reopen the content, see whether the alternative saved on the right image, and use an available read-aloud or screen-reader mode, or read only the text without seeing the image. If the platform drops the alternative, use visible body text or another editable publishing route. Do not call the task done when the text was lost.

### Success

Someone who does not see the image can still get the information or action it contributes; pure decoration does not repeatedly interrupt reading. The description matches the image and context and remains after saving. If platform behavior, the image's content, or real-reader experience is unverified, mark that limit rather than treating one filled field as accessibility acceptance.

### Common errors and recovery

- **The text says only “photo/screenshot”:** Ask why the image is present and name the fact or action a reader needs next.
- **The description repeats the nearby body:** If body text fully conveys the content, mark decoration according to platform rules or shorten the repetition. Do not make someone hear the same sentence twice.
- **An automatic description guessed wrong:** Correct it from what you can actually see and verify. Do not state an unknown identity or emotion as fact.
- **The chart is too dense:** Put essential trends, categories, or sourced values in nearby text. Use a short alternative to point there. Stop before publishing precise claims from uncertain data.
- **The platform has no alt-text control:** Write essential meaning in adjacent visible text and check that it works without the image. Choose another editable publishing route if needed.

### Assumptions, alternatives, and known side effects

This is an author-side improvement for ordinary content, not formal WCAG certification. Platforms differ in alt fields, decorative settings, and spoken output; follow the actual interface. Feedback from a nonvisual reader can help, but do your own available checks first rather than assigning them free acceptance work. Good description may reveal that a picture carries no information. It may stay, provided it does not get in the way.
