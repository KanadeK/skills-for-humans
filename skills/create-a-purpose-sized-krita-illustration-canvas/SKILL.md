## 中文

你要画一张给屏幕观看的原创插画，却还没有合适的工作底稿时，从画布决定开始。目标是像素尺寸和方向符合实际放置位置，背景是否透明已经想清楚，图层和文件名可识别。不要把屏幕像素与印刷 PPI 混作同一要求，也别为了虚构的未来用途把尺寸放到设备无法流畅编辑。

### 准备与输入

先记录成品拟放的位置及大致横竖比例，检查需不需要透明边缘。若用途方没有给明确像素要求，就选设备能顺畅处理的常规尺寸，保留可修改的工程；如果是印刷或色彩受控交付，先取得正式规格再做。

### 执行

1. 在 File 的 New 中选择自定义文档，设置宽高像素与方向，并让画幅比例对应预期展示区域。
2. 检查颜色模型与位深，普通屏幕插画选可用的 RGB 设置；在 Content 中明确背景为画布色还是透明层。
3. 给文档一个能识别本次用途的名称，建立后看边缘、比例与图层面板，不在错误画幅上开始正式绘画。
4. 用简短测试线检查画布能否流畅绘制，若方向、透明度或尺寸不合，尚未投入绘画前重新建正确画布。

### 完成、常见问题与恢复

空画布的像素大小、方向和背景状态与当前屏幕用途一致，文件可继续进入原画步骤。

- **比例不合：** 返回新建文档改宽高，不靠导出时硬拉伸。
- **透明区被白色遮住：** 查 Content 背景选项和背景层是否真的不透明。
- **绘制迟钝：** 在细画前降低不必要的像素尺寸或层数。

### 假设与边界

这只确定一张普通屏幕插画的工作画布，不承诺打印尺寸、色彩校准或平台压缩后的显示质量。新建文件仍需另行保存成 .kra。

## English

Use this before drawing an original illustration for a known screen placement. Finish with a canvas whose pixel dimensions and orientation fit that placement, with a deliberate transparent or opaque background and a recognizable document name. Screen pixel count and print PPI answer different questions; an enormous speculative canvas can make ordinary editing slow.

### Preparation and inputs

Record where the result will appear and its approximate aspect ratio, then decide whether transparent edges are needed. Without an explicit pixel specification, choose a manageable size for the device and keep an editable master. For color-controlled print work, obtain the actual production specification first.

### Execution

1. Open File > New, choose a custom document and enter pixel width, height and orientation matching the intended display area.
2. Inspect color model and bit depth, using a suitable RGB setting for ordinary screen art; choose canvas-color or transparent background in Content.
3. Give the document a purpose-specific name, create it and inspect edges, proportions and layer docker before starting the artwork.
4. Draw a disposable test stroke to check responsiveness. If dimensions, orientation or transparency are wrong, recreate the canvas before substantial work.

### Success, common problems, and recovery

The blank canvas visibly matches the current screen purpose in pixel size, orientation and background, and is ready for original drawing.

- **Wrong ratio:** Recreate with corrected width and height instead of stretching on export.
- **Transparency hidden:** Inspect Content background choice and opaque background layers.
- **Slow strokes:** Reduce unnecessary pixel size or layers before detailed painting.

### Assumptions and limits

This sets up one ordinary screen illustration, not a print size, calibrated color proof or guaranteed appearance after platform compression. A new document still needs an explicit .kra save.
