# Skills for Humans / 给人类的 Skill

> AI 有 Skill，人类也该有。
>
> Runtime: Human. Execution requires a body.

这是一个正在按公开规范构建的技能包：文件使用真正的 SKILL.md 格式，但读者、运行时和执行器都是人类。

首版将包含至少 15 个中英双语 Skill，覆盖家务、第一次尝试、尴尬但普通的社会任务，以及失败后的补救。内容七分认真有用，三分一本正经地好笑。

当前 main 只保存已经确认的产品定义和实施计划。完整内容将在独立分支通过验证与评审后合入。
